Watch the 4-minute walkthrough

Pitch Brands On Levanta Automatically: Message Brands. Recorded inside the app and narrated start to finish.

Read the video transcript

Another network, same chore. Levanta connects creators with brands that pay for influencer marketing. Pitching each approved brand by hand is the same chore as Creator Connections. Levanta Message Brands does the pitching, the same way Amazon Message Brands does.

Power User feature. Quick note on plans. Levanta Message Brands is a Power User feature. On the Beginner plan it is hidden from the sidebar. Upgrade any time in Settings, under Subscription.

What it needs. An approved Levanta account, a signed-in Levanta session in Chrome, and your Levanta API key in Settings. Email Extractor runs alongside and collects each brand's contact email.

Run status. Run status: usage, sent, the current brand, and the search term that surfaced it, filling in while a run goes.

The default message. The default message is sent when no template matches. Use brandName and campaignName in braces, and address and media kit if the brief asks for them. Keep it short and personable.

Follow-ups. Enable follow-ups sends a second message after six, twelve or twenty-four hours, with daysSinceMessage available for the wording.

Keywords or brand name. Keyword and brand filters decide who is contacted. Add the keywords or brands to target; leave it empty and every approved brand qualifies.

Skip lists. Skip keywords in campaign title and brands to skip take campaigns and brands out entirely. A skip always wins.

Never twice, and a cap. Exclude brands with messages already sent keeps it from pitching anyone twice. Daily message cap stops the run at that many sends. Start small.

Templates. Keyword and brand templates send a different pitch when a keyword or brand matches: name it, list the matchers, and add a few variations.

Run Levanta Now. Run Levanta Now opens Chrome on your Levanta session and works through the matching brands. Watch it run in the top bar keeps it on screen. Not pressed today.

Next step. Your next step: connect Levanta in Settings, write the default message, add one keyword, cap it at five, and run it once while you watch.
