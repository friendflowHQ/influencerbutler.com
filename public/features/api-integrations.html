Which butlers need your OpenAI key

AI butlers use your own OpenAI API key. You pay OpenAI directly for what you use (usually pennies), not Influencer Butler. A ChatGPT subscription does not work: ChatGPT and the OpenAI API are billed separately, so you need an API key with a little billing credit. Follow the OpenAI API setup guide.

  • AI Keyword Generator
  • Voiceover Butler
  • Benable Butler
  • Benable Comment Butler
  • Benable List Optimize
  • Facebook Group Builder
  • Social Posting Butler (AI images)
  • Deal Posting (caption voice and shorten titles)
  • Orders Butler (voiceover scripts)
  • YouTube Butler and Video Reload Butler (titles and translation)
  • Pinterest Butler (SEO copy)
  • Delete Posts and Delete Comments (image scan)

Included without a key: the AI Assistant and the free caption engine in the Chrome extension run on our servers and are part of your plan.

Other keys: the “AI title” style in Photo Reload and Video Reload uses an Anthropic key. Keepa, Fal.ai, and Ideogram are also separate keys that you bring yourself.

Read the video transcript

One panel, every key. Voiceover, Group Builder, the AI images, Product Research backfills: each needs a key. Instead of asking inside every butler, AI and Data Keys takes them once.

Included in the Beginner plan. Quick note on plans. AI and Data Keys is included in the Beginner plan, so everyone has it. On the Beginner plan the hosted AI covers a monthly allowance with no key at all; your own key always wins.

OpenAI. OpenAI first. One key powers the script writing, the captions and the AI images. Your key calls OpenAI directly and they bill your account, so the numbers here are estimates.

Chat model. Chat model picks the model Voiceover Butler writes with: best quality, balanced, fast, or cheapest.

Usage and spend cap. Usage this month: calls and estimated spend, by model. The soft spend cap warns you past a number; it never blocks a call, so set a hard cap in your OpenAI account if you need one.

Test Connection. Test Connection proves a key works and remembers when it was last tested. Run saved tests on startup re-checks every stored key when the app opens.

Keepa. Keepa is optional: with a key, Product Research backfills a product's full price and rank history the first time you look at it.

Fal and Ideogram. Fal is the cheapest provider for photographic AI images, and Ideogram the strongest for text inside images. AI Content Butler routes each style to the one that is connected and falls back to OpenAI.

The rest. YouTube Data, Google Places and Etsy keys sit below for the butlers that use them. Keys are stored encrypted on this computer.

Next step. Your next step: paste your OpenAI key, press Test Connection, and set a soft cap you would want to hear about.
