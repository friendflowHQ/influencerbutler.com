What’s in the box

  • Deal discovery by category, price drop, or keyword
  • Post state machine - drafts can’t accidentally publish
  • Daily-bucket aggregation so you don’t pile 30 deals on one day
  • Per-keyword tracking-day window (and exclude-last-month option)
  • Post builder with AI-templated captions in your tone
  • Promo code manager - codes get injected into the post automatically
  • Multi-platform auto-posting: Instagram, Instagram Threads, Facebook groups + pages, Telegram, Reddit, and Benable
  • Automatic link shortening if you’re connected (GeniusLink, URLGenius, Linktw.in, self-hosted)
  • Marketplace links for shoppers in other countries: post one link, a tagged link per country the product sells in, or a single smart link that routes each shopper to their own Amazon store (set your per-country tags in API Integrations)
  • Preview before anything goes live
  • Pairs with Data Refresh Butler so every deal hunt runs on fresh commission rates
