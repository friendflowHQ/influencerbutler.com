Drop short, friendly comments on Benable list items - AI-written from real Amazon product details, with a canned fallback when the API isn’t available.

Without this

You scroll Benable hoping to be noticed. Engagement is low. Real engagement - the kind that actually drives visits to your collection - takes hours a day you don’t have.

With Butler

Butler visits every list, reads each item, and posts a short, specific, on-brand comment. You set the tone, the caps, and the schedule.

How it saves you time, money, and headaches

  • Real engagement on Benable without burning your afternoons.
  • AI writes specific comments from real product details - not generic "nice list!" filler.
  • Caps + pacing + jitter keep your activity human-shaped.

What’s in the box

  • Storefronts list: paste Benable profile URLs, or import them from Benable Like Butler
  • Discover mode: scan benable.com/discover by category (Trending, Fashion, Beauty, Food, Travel, Home, Books, Health, Pets, Active Life, Wedding, Baby & Kids, Hobbies, Tech)
  • Comment text modes: AI + canned fallback, AI only, canned phrases only
  • OpenAI model picker (uses your own OpenAI key), tone field, min/max length, custom canned phrases
  • Caps: per-run, per-day, lifetime + every-Nth-collection / every-Nth-item sampling
  • Delay + jitter between comments to mimic human pacing
  • Built-in scheduler: start time + repeat interval, with last-run + next-run pills
  • History table: comments per creator, top content tier, recent activity, CSV export
  • Default dry-run: see what Butler would post before any text goes live

Benable Comment Butler: AI Comments, Dry Run First. Recorded inside the app and narrated start to finish.

Read the video transcript

A comment takes thought. A heart is quick. A comment takes thought. Comment Butler writes short comments on Benable list items for you.

A Pro butler, maybe hidden. It is a Pro butler. If it is missing under Benable Butler, open Show / Hide Butlers and turn it on.

Sign in to Benable first. Sign in to Benable here first. Watch it run, at the top, shows or hides the browser. Off and signed out, the run stops.

The box that matters most. Dry run is ticked at first. Ticked, the butler writes comments but posts none. Unticked, it posts each comment to Benable for real, with no extra confirmation.

Which profiles to visit. Add Benable profile links here, one per line. The butler walks every collection on each profile and looks at every item, until a cap stops it.

Borrow your Like Butler list. Set up Like Butler already? This copies its profile list here, replacing what is in the box.

Optional: Discover. Enable Discover mode to also scan Benable's Discover page. With no categories ticked, it scans the default Discover feed once.

Pick Discover categories. There are 14 categories, and Trending is ticked at first.

Amazon products only. Amazon-posted products only is the default. It opens each item and skips any with no Amazon link.

Who writes the words. Mode picks who writes: AI plus canned fallback, the default, AI only, or canned only. AI only skips an item the AI cannot write.

What the AI needs first. AI needs your OpenAI key, in AI and Data Keys. Without one, the default mode uses your canned phrases, and AI only will not start. If your Amazon Creators API is connected, the AI also reads each product's title and details.

Your own canned phrases. Canned phrases go here, one per line. It picks one not yet used on that item, favoring ones not used this run.

Length limits. AI comments must fit the length limits, 4 to 80 characters at first. It rejects any with a link, a question mark, an at-mention or a hashtag.

Model and tone. The model starts as gpt-4o-mini. Tone is a short phrase that steers the writing. It starts as short, friendly, complimentary.

Caps that keep it small. Per run is 5 and per day is 10 at first. Lifetime is 0. Zero means no limit, for per day and lifetime.

Every Nth collection or item. Every Nth collection and item skip some on purpose. 1 means every one, and 3 means every third.

A pause between comments. Delay between comments starts at 30 seconds, plus a random extra up to the jitter, 15 at first.

Start with Dry run ticked. Start Comment Butler begins the run, and shows the browser if Watch it run is on. For a first run, leave Dry run ticked.

Read what it wrote. In a dry run, each comment goes into a log file, marked not posted. The history table lists only posted comments, so open the log, or Download CSV.

How the stats count. In a dry run, Comments this run counts what it wrote. Lifetime posted does not go up, and the per run cap still applies.

After real posting. After real posting, the table shows each creator, how many comments were posted, and the latest comment's text.

Careful clearing the log. Clear all asks first, and Undo last clear brings the log back. Careful: the log is how it remembers items it already commented on.

Repeat on a schedule. Scheduler: Repeat every is in minutes, at least 15. Empty means once a day.

Turn the schedule on. Enable Schedule turns it on. The first run is at the Start time, or one repeat interval from now if that is empty. Scheduled runs use your saved settings, Dry run included.

Dry run first, then decide. So: run it dry, read every comment in the log, then untick Dry run, with small caps.
