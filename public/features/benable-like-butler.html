Watch the 4-minute walkthrough

Benable Like Butler: Auto-Like Collections, Free. Recorded inside the app and narrated start to finish.

Read the video transcript

Hearts by hand take forever. Tapping hearts on Benable collections by hand takes forever. Like Butler does it for you, and it is free.

Switch it on first. If it is missing under Benable Butler, open Show / Hide Butlers and turn it on. It can start hidden.

Sign in to Benable first. Sign in to Benable here first. Watch it run, at the top, shows or hides the browser. Off and signed out, the run stops.

Who to visit. Add Benable profile links here, one per row. Each row's Max likes box is optional. Empty means it uses the main limit.

Optional: Discover. Discover is optional. It also likes collections, and the items inside them, from Benable's Discover page, after your profiles. You can run with Discover alone.

Pick Discover categories. Pick from 14 categories, like Fashion and Tech. Trending is ticked at first. Only ticked ones are visited.

What gets a heart. Then what gets a heart: collections, items inside them, or both. With both on, collections come first.

Cap items per collection. Max items per collection stops one huge collection using up the run. It starts at 50.

One total for the run. Max likes per run is one total for the whole run, across all profiles and Discover. It starts at 10.

Wait between hearts. Delay between likes starts at 8 seconds, plus a small random extra. It accepts 2 to 90.

Three speed presets. Presets: Fast is 3 seconds, Normal is 8, Careful is 15. For a first run, pick Careful.

Check all is ticked. Check all is ticked at first. It ignores the butler's own record of past runs. Untick it, and it also skips anything it already logged.

These are real likes. Start begins the run in the browser. There is no dry run, so every heart is a real like, and this app cannot take one back.

Pause and Stop. Pause holds a run. Stop appears only during a run, and ends it and closes the browser.

Pick a start time. Scheduler: pick a start time. The first run happens then, and a time in the past moves forward to about a minute from now.

How often to repeat. Repeat every is in minutes, from 15 to 720. Pick how often the run should repeat.

Turn the schedule on. Enable Schedule turns it on. While it is on, the profiles, Discover and limits lock, along with Start, Stop and Pause. Stop Schedule unlocks them.

What it has liked. History lists each creator you liked, with counts and latest activity. Search it, or filter by 24 hours, 7 days or 30 days.

Clearing the log. Clear all empties the log, after asking. Undo last clear brings it back. Total likes is counted from that log, so Reset total clears it too.

Where the list goes next. Your profile list can be copied into Comment Butler, a Pro butler, with its Import button.

Your first run. First run: one profile, Max likes 10, Careful, Watch it run on. Then press Start yourself.
