    Send to another computer

    Use the desktop app on a different computer? On that computer open Settings, Extension, and click Connect another computer to get a code, then type it below. This browser must be signed in with the same license key as that app.

    1. Sign in here. Open Account in this popup and enter the same license key the desktop app uses. The Account section then shows Connected as your email.
    2. Get a code on the other computer. In the desktop app go to Settings, Extension, and click Connect another computer. The code lasts 2 minutes.
    3. Type the code below and click Link device. Your computer then shows under Linked computers.
