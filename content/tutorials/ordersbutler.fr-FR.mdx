## Ce que fait Orders Butler

Orders Butler est la source de données pour presque tous les espaces côté Amazon. Il se connecte à Amazon avec votre session Chrome existante, parcourt votre historique de commandes page par page et stocke le résultat dans une base locale.

Si Orders Butler est obsolète, tous les espaces Amazon prennent des décisions avec des données périmées.
