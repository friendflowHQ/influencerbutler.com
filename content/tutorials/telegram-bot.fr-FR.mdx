## Ce que cela fait

Deals Influencer Butler peut publier les images de vos produits et leurs légendes directement dans un canal Telegram. Pour le configurer, vous connectez un bot Telegram sur le panneau **API Integrations**. Il vous faut deux valeurs : un **token du bot** et l'**ID du canal (chat)** dans lequel vous voulez publier. Toute la configuration prend environ cinq minutes. Voici le guide complet.

## 1. Créez un bot avec BotFather

Dans Telegram, recherchez **@BotFather** (le bot officiel, il porte la coche bleue de vérification) et ouvrez une discussion avec lui. Envoyez la commande `/newbot`. BotFather demande un nom affiché, puis un nom d'utilisateur qui doit se terminer par `bot`, par exemple `gardenlovers_deals_bot`.

![Recherche globale de @BotFather dans Telegram, avec le bot officiel vérifié mis en évidence en haut des résultats](/assets/tutorials/telegram-bot/telegram-botfather-newbot.png)

## 2. Copiez le token du bot

Une fois le nom d'utilisateur accepté, BotFather répond avec votre token d'accès. Il ressemble à `123456789:ABCdef...`. Copiez-le. Gardez-le privé : toute personne disposant de ce token peut publier en tant que votre bot.

De retour dans InfluencerButler, ouvrez **API Integrations** et collez le token dans le champ **Telegram Bot Token** de la carte du bot Telegram.

## 3. Ajoutez le bot à votre canal en tant qu'administrateur

Ouvrez le canal Telegram dans lequel vous voulez publier des offres, ou créez-en un nouveau. Ouvrez la liste des **Administrateurs** du canal, choisissez **Ajouter un administrateur**, recherchez votre bot par son nom d'utilisateur et ajoutez-le. Donnez-lui au moins l'autorisation **Publier des messages**.

![Écran Administrateurs du canal, où vous choisissez Ajouter un administrateur pour ajouter le bot](/assets/tutorials/telegram-bot/telegram-channel-admins.png)

## 4. Trouvez votre ID de canal / chat

Il existe deux formats :

- **Canal public** : utilisez l'identifiant public, par exemple `@gardenloversdeals`. C'est l'option la plus simple.
- **Canal privé** : utilisez l'ID numérique, qui commence par `-100`, par exemple `-1001234567890`. Pour le trouver, transférez n'importe quel message du canal vers un bot d'aide comme **@getidsbot**, qui répond avec l'ID numérique.

![Panneau d'informations du canal montrant le @identifiant public qui sert d'ID de canal / chat](/assets/tutorials/telegram-bot/telegram-channel-id.png)

## 5. Collez les valeurs et testez

Collez l'identifiant ou l'ID numérique dans le champ **Channel / Chat ID**, puis cliquez sur **Test Connection**. Quand tout est bien configuré, le statut passe au vert et affiche "Connected".

## Ce qui est publié

Une fois connecté, Deals Influencer Butler publie dans ce canal via l'endpoint `sendPhoto` de la Bot API de Telegram. Chaque publication porte l'image du produit de votre ligne d'offre et une légende construite à partir du modèle de votre compositeur de publications. Rien n'est envoyé tant que vous ne publiez pas, donc connecter le bot à l'avance est sans risque.

## Problèmes courants

- **Le test échoue avec "chat not found"** : le bot n'est pas encore dans le canal, ou l'identifiant / ID est incorrect. Revérifiez l'étape 3 et l'étape 4.
- **Le test échoue avec "not enough rights"** : le bot est dans le canal mais n'est pas administrateur, ou n'a pas l'autorisation Publier des messages. Rouvrez la liste des administrateurs du canal et accordez-la.
- **Les publications n'arrivent nulle part après un changement de nom d'utilisateur** : si vous avez renommé l'identifiant public du canal, mettez à jour le champ Channel / Chat ID pour qu'il corresponde, puis testez à nouveau.
