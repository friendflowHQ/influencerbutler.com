## Ce que fait Facebook Goldmine

Facebook Goldmine analyse les groupes Facebook auxquels vous appartenez et récolte les publications déjà virales, pour que vous réutilisiez les plus fortes au lieu de deviner ce qui va marcher. Vous fixez un nombre minimum de réactions, et la collecte ne conserve que les publications qui atteignent ou dépassent ce seuil.

Les publications récoltées arrivent dans une file de révision. Vous approuvez celles que vous voulez, et Facebook Goldmine republie les publications approuvées sur votre Page Facebook, puis les repartage dans vos groupes par rotation (un ensemble de groupes différent à chaque cycle, pour ne pas saturer toujours les mêmes). Il utilise la même session Facebook que Deals Butler, vous vous connectez donc une seule fois.

## Avant de commencer

1. Connectez-vous d'abord à votre compte Facebook depuis Deals Butler. Facebook Goldmine réutilise cette session et n'a pas sa propre connexion.
2. Assurez-vous d'appartenir déjà aux groupes de niche que vous voulez analyser. Facebook Goldmine lit les groupes dont vous êtes membre.
3. Si vous prévoyez de republier, gardez l'URL de votre Page Facebook à portée de main.

## Comment l'utiliser

1. Dans le menu de gauche, ouvrez **Facebook Butler**, puis **Facebook Goldmine**.
2. Sous **Paramètres de collecte**, choisissez quel compte analyse avec le sélecteur **Compte Facebook**.
3. Réglez **Réactions minimum** sur le seuil qu'une publication doit franchir pour être conservée (la valeur par défaut est 100). Seules les publications à ce nombre de réactions ou plus sont récoltées.
4. Réglez éventuellement **Publications max par groupe** (0 conserve toutes celles trouvées) et **Tentatives de défilement par groupe** (jusqu'où le défilement va dans chaque groupe).
5. Indiquez éventuellement des ID de groupe dans **Ignorer ces ID de groupe**, séparés par des virgules, pour les groupes à ne pas analyser.
6. Sous **Republier et repartager**, ajoutez l'**URL de votre Page Facebook** où les publications approuvées seront republiées. Laissez **Ajouter une ligne de crédit aux légendes republiées** activé pour créditer le groupe source, et modifiez la **Ligne de crédit** si vous le souhaitez (utilisez {source} pour le nom du groupe). Réglez **Groupes par cycle de repartage** sur le nombre de groupes touchés à chaque partage.
7. Laissez **Voir l'exécution** activé si vous voulez que le navigateur passe au premier plan pour suivre le déroulement, ou désactivez-le pour une exécution en arrière-plan.
8. Cliquez sur **Démarrer Facebook Goldmine**. Les paramètres s'enregistrent automatiquement au fur et à mesure de votre saisie, il n'y a donc pas de bouton d'enregistrement.
9. Une fois l'analyse terminée, ouvrez la **File de révision**, approuvez les publications à republier et ignorez les autres. Utilisez **Actualiser** pour recharger la liste.
10. Pour garder la file à jour en pilote automatique, définissez une **Heure de début** et un intervalle dans **Répéter tous les** sous **Planificateur**, puis cliquez sur **Activer la planification**. Utilisez **Arrêter la planification** pour la désactiver.

## Notes

- Facebook Goldmine ne republie et ne repartage que les publications que vous avez approuvées dans la file de révision. Rien n'est republié automatiquement sans votre approbation.
- Il lit les groupes dont vous êtes déjà membre. Il ne rejoint pas de nouveaux groupes à votre place.
- Le repartage alterne entre un ensemble de groupes différent à chaque cycle pour ne pas saturer toujours les mêmes. Publiez dans les groupes en respectant leurs règles.
- Si la collecte ne parvient pas à lire Facebook, vérifiez que vous êtes toujours connecté via Deals Butler et réessayez.
