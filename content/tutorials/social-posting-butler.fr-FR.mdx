## Ce que fait Social Posting Butler

Social Posting Butler est l'endroit où vous chargez vos propres posts et les laissez partir selon une planification, vers toutes les destinations sociales que vous utilisez déjà. Au lieu d'un butler qui trouve des offres pour vous, c'est un butler que vous nourrissez : votre photo (ou une que vous générez avec l'IA), votre texte, votre lien, et quand il doit être publié. Il publie ensuite via le même moteur de publication que le reste de l'app, donc les groupes et pages Facebook, Instagram, Threads, Telegram, Reddit et Pinterest fonctionnent de la même façon ici.

C'est aussi le hub auquel les autres butlers confient leurs posts, donc tout ce que vous avez planifié apparaît au même endroit.

## Les deux types de post

Chaque post que vous composez est de l'un des deux types :

- **Planifier une fois** : se publie une seule fois à la date et l'heure que vous choisissez, puis c'est terminé.
- **Permanent** : se republie selon sa propre cadence pour toujours, jusqu'à ce que vous le désactiviez. Choisissez un intervalle simple (toutes les quelques heures ou jours) ou des jours précis de la semaine à une heure fixe. C'est l'option "réglez-le et oubliez-le" pour du contenu qui reste pertinent, comme un rappel récurrent, un conseil signature ou une recommandation toujours d'actualité.

Vous pouvez aussi utiliser **Publier maintenant** pour publier immédiatement sans l'enregistrer dans votre bibliothèque.

## Composer un post

1. Ouvrez **Social Posting Butler** et allez dans l'onglet **Composer**.
2. Écrivez votre **texte**.
3. Choisissez une **photo** :
   - **Importer la vôtre** : choisissez une ou plusieurs images sur votre ordinateur (jusqu'à 10). Elles sont copiées dans l'app pour rester disponibles même si vous déplacez les originales.
   - **Générer avec l'IA** : décrivez l'image que vous voulez et Butler en crée une pour vous. Cela utilise votre clé OpenAI, la même que le reste de l'app pour les images IA.
   - **Aucune photo** : un post en texte seul.
4. Ajoutez votre **lien**, s'il y en a un. Activez **Publier le lien dans le premier commentaire** si vous préférez que le lien arrive en premier commentaire plutôt que dans le texte. C'est une astuce courante pour garder le texte propre et éviter qu'une plateforme rétrograde un post contenant un lien sortant.
5. Choisissez vos **destinations**, ou laissez tout décoché pour utiliser toutes les destinations que vous avez activées.
6. Choisissez **quand publier** : Publier maintenant, Planifier une fois ou Permanent.
7. Laissez **Regarder faire** activé si vous voulez voir la fenêtre du navigateur pendant la publication. Désactivez-le pour l'exécuter en arrière-plan.
8. Cliquez sur **Enregistrer dans la bibliothèque** (pour les posts planifiés ou permanents) ou sur **Publier maintenant**.

## Voir ce qui arrive

L'onglet **À venir** montre chaque post planifié ou permanent, dans la vue que vous préférez :

- **Calendrier** : une grille hebdomadaire avec chaque post à son jour et son heure. Utilisez les flèches pour passer d'une semaine à l'autre.
- **Cartes** : une grille orientée photo, une carte par post à venir.
- **Tableau** : une liste triable. Cliquez sur un en-tête de colonne pour trier par heure, post ou type.

Depuis n'importe quelle vue, vous pouvez **Modifier** un post (il se rouvre dans Composer), **Publier maintenant** ou le **Supprimer**. Un post permanent montre chaque heure à venir où il se publiera au cours des prochaines semaines.

## Destinations

L'onglet **Destinations sociales** montre quelles destinations vous avez activées. Vous les activez et les configurez (connexions, clés d'API, groupes et canaux cibles) dans Deals Butler, et Social Posting Butler respecte le même ensemble. Utilisez le bouton **Gérer les destinations** pour y aller.

## Où vont les données

Votre bibliothèque de posts et sa planification vivent sur votre ordinateur, à côté des autres données de l'app. Les posts se publient via le moteur de publication partagé, donc un post que vous envoyez ici apparaît dans votre historique de publication comme n'importe quel autre.

## Problèmes courants

- **"Aucune destination activée pour le moment"** : activez d'abord au moins une destination dans Deals Butler, puis revenez.
- **L'image IA échoue** : configurez votre clé OpenAI dans API Integrations. La même clé alimente toutes les images IA de l'app.
- **Un post planifié ne s'est pas publié** : vérifiez que le post est activé et que l'automatisation n'est pas en pause globale. Les posts permanents sautent une heure manquée (par exemple si l'ordinateur était en veille) plutôt que de la publier en retard.
- **Le lien n'est pas dans le texte** : si vous avez activé "Publier le lien dans le premier commentaire", le lien est publié en premier commentaire, comme prévu.
