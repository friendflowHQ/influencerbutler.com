## What TikTok Like Butler does

TikTok Like Butler opens TikTok in a browser and likes the recent videos of the accounts you list. You add one or more usernames, set how many likes to give and how long to wait between them, then start a run or let the scheduler run it on a cadence. Every like is logged so you can review, search, and export the history by creator.

## Before you start

- Open **TikTok Butler** in the left menu, then **TikTok Like Butler**.
- Keep **👀 Watch it run** checked (the default) the first time so the browser stays visible. Sign in to TikTok in that window once; the session is remembered for later runs.
- Know which accounts you want to like. You can enter a username (**@creator**) or a full profile URL (tiktok.com/@creator).

## How to use it

1. In the **TikTok accounts** card, type a username or profile URL. Click **Add another TikTok account** to list more.
2. Leave **Like every recent video** on to like every recent post each run, or turn it off to skip posts already liked on a previous run.
3. Under **Run settings**, set **Max likes per run** (default 10), **Delay between likes** in seconds (default 8), and **Recent posts per account** (how far back to scan, default 30).
4. Pick a speed preset if you like: **Fast**, **Normal**, or **Careful**. These just set the delay for you; **Careful** is gentler on your account.
5. Click **Start TikTok Like Butler**. Watch the browser tap through each account's recent videos, or click **Pause** or **Stop** at any time.
6. To run on a cadence, use the **Scheduler** card: set a **Start time** and **Repeat every** interval in minutes, then click **Enable Schedule**. Click **Stop Schedule** to turn it off.

## Notes

- **TikTok Like Butler is in beta.** Some parts may not work fully yet while we build it out.
- While the scheduler is active, the manual controls and account list lock. Click **Stop Schedule** to unlock them.
- The **History** section tracks liked content by creator. Use **Refresh** to update it, **Download CSV** to export the raw log, and **Clear all** to reset it (with an **Undo last clear**).
- Two totals sit at the top: **Total likes given** (lifetime) and **Likes this run**. Each has its own reset button.
- Go slow to protect your account: a higher **Delay between likes** and the **Careful** preset look more human than rapid-fire liking.
