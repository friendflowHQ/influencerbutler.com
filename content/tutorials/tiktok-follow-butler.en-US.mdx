## What TikTok Follow Butler does

TikTok Follow Butler follows a list of TikTok accounts you choose, one account at a time. You paste in usernames or profile links, set how many to follow per run and how long to wait between each, then start it. The butler opens each profile, taps **Follow**, and records what it did. A running total and a searchable history show every account it has followed.

## Before you start

- Open **TikTok Butler** in the left menu, then **TikTok Follow Butler**.
- Turn on **👀 Watch it run** (on by default) the first time so the browser stays visible. Sign in to TikTok in that window when it opens, so the butler can follow as you.
- Have the usernames or profile URLs of the accounts you want to follow ready.

## How to use it

1. In the **Accounts to follow** card, type a username (like @creator) or paste a profile URL (like tiktok.com/@creator). Click **Add another TikTok account** for each one you want to add.
2. In **Run settings**, set **Max follows per run** (default 20) and **Delay between follows** in seconds (default 12). You can use the **Fast**, **Normal**, or **Careful** speed presets to set the delay for you.
3. Keep **👀 Watch it run** on for the first run, then click **Start TikTok Follow Butler**.
4. Watch the **Live activity** feed and the totals: **Follows this run** ticks up as it works, and **Total follows given** tracks the lifetime count.
5. Use **Pause** to hold, or **Stop** to end the run early.

To run on a cadence instead, use the **Scheduler** card: pick a **Start time**, set **Repeat every** (in minutes), and click **Enable Schedule**. While a schedule is active the manual controls lock; click **Stop Schedule** to unlock them again.

## Notes

- TikTok Butler is in beta, so some parts may still be rough while we build it out.
- The butler follows each account once. Accounts you already follow are skipped, so you can safely leave a list in place across runs.
- The **History** section lets you search by creator, filter by time range (24h, 7d, 30d), sort the table, and **Download CSV** of the raw follow log. **Clear all** wipes the history, with an **Undo last clear** option right after.
- Keep the delay reasonable and the per-run cap modest. Following too fast can trip TikTok's limits.
