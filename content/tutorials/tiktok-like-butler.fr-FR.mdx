## Ce que fait TikTok Like Butler

TikTok Like Butler ouvre TikTok dans un navigateur et aime les vidéos récentes des comptes que vous indiquez. Vous ajoutez un ou plusieurs noms d'utilisateur, réglez le nombre de mentions J'aime à donner et le délai entre chacune, puis lancez une exécution ou laissez le planificateur la lancer selon une cadence. Chaque mention J'aime est enregistrée pour que vous puissiez consulter, rechercher et exporter l'historique par créateur.

## Avant de commencer

- Ouvrez **TikTok Butler** dans le menu de gauche, puis **TikTok Like Butler**.
- Laissez **👀 Watch it run** coché (l'option par défaut) la première fois pour que le navigateur reste visible. Connectez-vous à TikTok dans cette fenêtre une fois ; la session est mémorisée pour les exécutions suivantes.
- Sachez quels comptes vous voulez aimer. Vous pouvez saisir un nom d'utilisateur (**@creator**) ou une URL de profil complète (tiktok.com/@creator).

## Comment l'utiliser

1. Dans la carte **TikTok accounts**, saisissez un nom d'utilisateur ou une URL de profil. Cliquez sur **Add another TikTok account** pour en ajouter d'autres.
2. Laissez **Like every recent video** activé pour aimer chaque vidéo récente à chaque exécution, ou désactivez-le pour ignorer les publications déjà aimées lors d'une exécution précédente.
3. Dans **Run settings**, réglez **Max likes per run** (par défaut 10), **Delay between likes** en secondes (par défaut 8) et **Recent posts per account** (jusqu'où remonter lors du scan, par défaut 30).
4. Choisissez une vitesse prédéfinie si vous le souhaitez : **Fast**, **Normal** ou **Careful**. Elles règlent simplement le délai à votre place ; **Careful** est plus douce pour votre compte.
5. Cliquez sur **Start TikTok Like Butler**. Regardez le navigateur parcourir les vidéos récentes de chaque compte, ou cliquez sur **Pause** ou **Stop** à tout moment.
6. Pour une exécution récurrente, utilisez la carte **Scheduler** : définissez **Start time** et l'intervalle **Repeat every** en minutes, puis cliquez sur **Enable Schedule**. Cliquez sur **Stop Schedule** pour le désactiver.

## Notes

- **TikTok Like Butler est en bêta.** Certaines parties peuvent ne pas être totalement opérationnelles pendant que nous le finalisons.
- Lorsque le planificateur est actif, les commandes manuelles et la liste des comptes se verrouillent. Cliquez sur **Stop Schedule** pour les déverrouiller.
- La section **History** suit le contenu aimé par créateur. Utilisez **Refresh** pour l'actualiser, **Download CSV** pour exporter le journal et **Clear all** pour la réinitialiser (avec **Undo last clear**).
- Deux totaux figurent en haut : **Total likes given** (cumul) et **Likes this run**. Chacun a son propre bouton de réinitialisation.
- Allez doucement pour protéger votre compte : un **Delay between likes** plus élevé et l'option **Careful** paraissent plus humains qu'une rafale de mentions J'aime.
