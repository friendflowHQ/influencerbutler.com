## Ce que fait Instagram Butler

Instagram Butler est la version côté-Instagram d'Amazon Butler : il envoie des DM de premier contact aux cibles que vous avez identifiées, avec des modèles de message qui tournent et les mêmes garde-fous (cooldowns par cible, listes de skip, filtres par abonnés). C'est l'espace que vous utilisez quand vous voulez pitcher des marques sur Instagram directement plutôt que d'attendre qu'elles vous trouvent.

Il se marie naturellement avec **Messenger Butler** (qui gère les conversations en cours) et avec **Instagram Goldmine** (qui découvre les personnes à qui il vaut la peine d'écrire). Instagram Butler est spécifiquement l'étape *premier contact*.

## Avant de commencer

- **Un compte Instagram connecté** dans Chrome. Instagram Butler utilise votre session existante.
- **L'URL de votre boutique Amazon** dans la barre du haut - utilisée dans les modèles via `{storefrontUrl}`.
- **Une source de cibles**: handles collés à la main, listes d'abonnés de votre compte, ou imports depuis Instagram Goldmine.

## Setup : le modèle de message

Ouvrez la carte **Messages initiaux**. C'est là que vivent vos DM de premier contact. Deux règles clés :

1. **Écrivez 3-5 variantes** de votre accroche. Instagram détecte les patterns de DM identiques et rate-limite les comptes qui les envoient. Des variantes comme "Salut ! J'ai vu ton post sur X, j'adorerais collaborer" / "Hello ! Ton contenu sur Y a attiré mon attention, on pourrait discuter ?" tournent par cible.
2. **Utilisez les marqueurs**: `{storefrontUrl}` substitue votre lien boutique ; `{address}` et `{mediakit}` tirent depuis les valeurs sauvegardées de votre profil. Gardez les variantes courtes - les premiers DM qui se lisent comme un pitch sont ignorés.

Mettez **initialMessageMode** sur `random` (défaut) pour que Butler choisisse une variante par cible plutôt que de toujours utiliser la première.

## Choisir les cibles

Le menu déroulant **Mode de cibles** décide à qui Instagram Butler envoie un message :

- **new-followers**: vos abonnés les plus récents. Utile pour convertir les nouveaux abonnements en vraies conversations.
- **manual-handles**: une liste que vous collez à la main. À utiliser quand vous avez curaté une liste cible (par ex. depuis Instagram Goldmine).
- **suggested-from-graph**: le graphe "suggéré pour vous" d'Instagram, parcouru depuis un compte semence.

La plupart des utilisateurs au démarrage prennent **new-followers** + **manual-handles** les premières semaines jusqu'à trouver leur rythme.

## Filtres qui comptent

- **followersLimitMin / followersLimitMax**: passez les comptes hors de cette plage. Utile pour rester sur les micro-influenceurs (par ex. 1K-50K) et éviter à la fois les comptes spam et les méga-comptes injoignables.
- **skipBrandsRaw**: noms de marque séparés par retour à la ligne à ne jamais contacter. Utile pour exclure les concurrents directs ou les marques avec lesquelles vous avez déjà travaillé.
- **skipTitleRaw**: mots-clés séparés par retour à la ligne. Si la bio ou les titres de posts récents d'une cible contiennent l'un d'eux, on passe. Aide à éviter les cibles hors niche.
- **excludeAlreadyMessaged**: laissez activé. Empêche Butler de re-contacter le même handle.

## Votre première passe de prise de contact

1. Ouvrez **Instagram Butler** dans la navigation (sous le toggle parent Instagram Butler).
2. Confirmez vos variantes dans **Messages initiaux**.
3. Choisissez un mode de cible et confirmez les filtres.
4. Mettez un **cap quotidien** prudent (démarrez à 15-25 DM/jour sur un compte nouveau).
5. Cliquez sur **Lancer**.

Une fenêtre Chrome s'ouvre. Butler parcourt chaque cible, ouvre son profil, ouvre les DM et envoie une de vos variantes. Le rythme est intégré - typiquement 2-5 minutes par DM avec jitter aléatoire.

## Règles de rate-limit d'Instagram

Instagram est la plateforme la plus stricte avec laquelle Butler interagit :

- **30 premiers jours** sur un compte nouveau : 15-25 DM/jour max.
- **Comptes établis** : 40-60 DM/jour tenables.
- **Plus de 80/jour** est en zone signalée - les comptes sont DM-bloqués pendant 24-72 heures.

Les valeurs par défaut de Butler (jitter, cooldowns, rythme) sont calibrées pour la sécurité - n'écrasez pas agressivement.

## Où vont les données

L'historique de DM par run est journalisé dans le cache preseed. Une fois un DM envoyé, le handle passe automatiquement dans la liste do-not-message (si `excludeAlreadyMessaged` est activé).

## Pièges courants

- **Bannière "Action bloquée par Instagram"**: vous avez envoyé trop de DM trop vite. Butler détecte le blocage, arrête l'exécution et met en pause TOUS les envois Instagram (messages, publications d'offres, mentions J'aime, changements d'amis proches) pendant une période de repos pour que le blocage n'empire pas ; les outils de collecte seule continuent de fonctionner, et vous recevez un e-mail. Par défaut le repos dure 3 jours ; modifiez-le avec **Pause après un blocage Instagram (jours)** dans les réglages d'Instagram Butler, et les blocages répétés se reposent plus longtemps d'eux-mêmes. Les envois reprennent automatiquement, ou reprenez plus tôt avec le bouton **Reprendre les envois Instagram** de la bannière du Tableau de bord. À la reprise, baissez votre cap quotidien.
- **Le premier DM arrive dans les demandes de message, pas dans la boîte de réception**: Instagram route les DM des non-abonnés vers "Demandes" plutôt que la boîte. Hors du contrôle de Butler.
- **Les modèles paraissent scriptés**: même en faisant tourner 5 variantes, ça devient daté à l'échelle. Rafraîchissez vos variantes toutes les 2-3 semaines.
- **Connexion manuelle en plein run**: Instagram demande parfois une vérification. Résolvez-la dans la fenêtre Chrome lancée, cliquez sur Reprendre.
