## What Facebook Goldmine does

Facebook Goldmine scans the Facebook groups you belong to and collects the posts that are already going viral, so you can repurpose the strongest ones instead of guessing what will land. You set a minimum number of reactions, and the harvest keeps only the posts at or above that bar.

Harvested posts land in a review queue. You approve the ones you want, and Facebook Goldmine reposts approved posts to your Facebook Page, then reshares them into your groups on rotation (a different set of groups each cycle, so you do not spam the same ones). It uses the same signed-in Facebook session as Deals Butler, so you sign in once.

## Before you start

1. Sign in to your Facebook account in Deals Butler first. Facebook Goldmine reuses that session and does not have its own sign-in.
2. Make sure you already belong to the niche groups you want scanned. Facebook Goldmine reads the groups you are a member of.
3. If you plan to repost, have your Facebook Page URL ready.

## How to use it

1. In the left menu, open **Facebook Butler**, then **Facebook Goldmine**.
2. Under **Harvest settings**, pick which signed-in account scans with the **Facebook account** selector.
3. Set **Minimum reactions** to the bar a post must clear to be kept (the default is 100). Only posts at or above this many reactions are harvested.
4. Optionally set **Max posts per group** (0 keeps every viral post it finds) and **Scroll attempts per group** (how far it scrolls each group).
5. Optionally list any group IDs in **Skip these group IDs**, comma separated, for groups you do not want scanned.
6. Under **Repost and reshare**, add **Your Facebook Page URL** where approved posts should be reposted. Keep **Add a credit line to reposted captions** on to credit the source group, and edit the **Credit line** if you like (use {source} for the group name). Set **Groups per reshare cycle** to how many groups each reshare touches.
7. Leave **Watch it run** on if you want the browser to come to the front so you can follow along, or turn it off to run in the background.
8. Click **Start Facebook Goldmine**. Settings auto-save as you type, so there is no Save button.
9. When the scan finishes, open the **Review queue**, then approve the posts you want reposted and skip the rest. Use **Refresh** to reload the list.
10. To keep the queue fresh on autopilot, set a **Start time** and **Repeat every** interval under **Scheduler**, then click **Enable Schedule**. Use **Stop Schedule** to turn it off.

## Notes

- Facebook Goldmine only reposts and reshares posts you have approved in the review queue. Nothing is reposted automatically without your approval.
- It reads the groups you are already a member of. It does not join new groups for you.
- Resharing rotates through a different set of groups each cycle to avoid spamming the same ones. Post to groups within their own rules.
- If the harvest cannot read Facebook, confirm you are still signed in through Deals Butler and try again.
