## Ce que fait l'extension

L'extension Chrome d'Influencer Butler est une compagne gratuite qui travaille pendant que vous naviguez sur Amazon normalement. Elle ajoute quatre outils:

1. **Scanner de vidéos**: sur n'importe quelle page produit, un panneau montre combien de vidéos possède le produit et qui les a faites: influenceur, marque ou client. C'est le paysage concurrentiel du carrousel que vous rejoindriez.
2. **Détecteur de manques de contenu**: sur votre historique de commandes Amazon, un clic analyse les produits que vous avez déjà achetés et signale ceux qui ont peu ou zéro vidéos d'influenceurs. Vous possédez déjà ces produits: ce sont les vidéos les plus rapides à tourner.
3. **Sceau Butler Approved**: un produit obtient le sceau quand il se vend activement, qu'une place d'influenceur est libre dans le carrousel vidéo, qu'il est en stock et qu'il dépasse votre prix plancher. Chaque critère affiche réussi ou échoué, vous savez toujours pourquoi.
4. **Bilan du storefront**: sur votre propre page storefront, un clic vérifie vos vidéos: étiquettes produit manquantes, sur-étiquetage et produits étiquetés devenus indisponibles.

Tout fonctionne sans compte. Connecter votre clé de licence est facultatif et ajoute la synchronisation avec votre tableau de bord web.

## Installer l'extension

- [ ] Ouvrez la fiche du Chrome Web Store depuis influencerbutler.com/extension et cliquez sur **Ajouter à Chrome** {#install}
- [ ] Épinglez l'extension: cliquez sur l'icône puzzle dans la barre de Chrome, puis sur l'épingle à côté d'Influencer Butler {#pin}
- [ ] Ouvrez n'importe quelle page produit Amazon; le panneau Influencer Butler apparaît dans le coin {#first-product}

## Lire le panneau vidéos

- [ ] Sur une page produit, repérez le panneau flottant **Influencer Butler** (cliquez sur son en-tête pour le replier ou le déplier) {#panel}
- [ ] **Video competition** affiche les comptes: vidéos d'influenceurs, de marque et de clients, plus celles que la page n'a pas classées {#counts}
- [ ] **Butler Approved** liste les quatre critères avec une marque réussi ou échoué; réglez les seuils dans les paramètres du popup {#seal}
- [ ] **Break-even math** estime les ventes et vues nécessaires pour couvrir votre temps; ajustez la commission et les vues à votre niche {#math}

## Analyser vos commandes pour trouver les manques de contenu

- [ ] Allez dans votre historique de commandes Amazon (Retours et Commandes) {#orders}
- [ ] Dans le panneau, cliquez sur **Scan these orders**; l'extension vérifie chaque produit un par un, à un rythme mesuré {#scan-orders}
- [ ] Les produits avec peu ou zéro vidéos d'influenceurs reçoivent un badge rouge **content gap**: ce sont vos victoires les plus faciles {#gaps}

## Vérifier votre storefront

- [ ] Ouvrez votre propre page storefront (amazon.com/shop/votrepseudo) et faites défiler pour charger vos vidéos {#storefront}
- [ ] Cliquez sur **Check my storefront** dans le panneau {#scan-storefront}
- [ ] Passez en revue les résultats: les vidéos sans étiquettes ne rapportent rien, les vidéos sur-étiquetées diluent les clics et les produits indisponibles gaspillent des étiquettes {#storefront-results}

## Synchroniser avec votre tableau de bord (facultatif)

- [ ] Cliquez sur l'icône de l'extension pour ouvrir le popup {#popup}
- [ ] Collez votre clé de licence Influencer Butler sous **Account** et cliquez sur **Connect** (les clés d'essai fonctionnent aussi) {#connect}
- [ ] Vos découvertes se synchronisent automatiquement; retrouvez-les sous **Extension** dans votre tableau de bord sur influencerbutler.com/dashboard/extension {#dashboard}

## Astuces

- L'extension n'explore jamais Amazon en arrière-plan. Les analyses ne s'exécutent que lorsque vous cliquez sur un bouton et se rythment comme une personne qui navigue.
- Votre clé de licence est stockée uniquement dans le stockage local de l'extension, dans votre navigateur.
- Renseignez votre pseudo de storefront dans les paramètres du popup pour que l'extension reconnaisse instantanément votre propre storefront.
