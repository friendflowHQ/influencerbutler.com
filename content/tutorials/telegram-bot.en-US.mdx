## What this does

Amazon Deals can post your product images and captions straight into a Telegram channel. To wire it up you connect a Telegram bot on the **API Integrations** panel. You need two values: a **bot token** and the **channel (chat) ID** you want to post into. The whole setup takes about five minutes. Here is the full walkthrough.

## 1. Create a bot with BotFather

In Telegram, search for **@BotFather** (the official bot, it has a blue verified check) and open a chat with it. Send the command `/newbot`. BotFather asks for a display name, then for a username that must end in `bot`, for example `gardenlovers_deals_bot`.

## 2. Copy the bot token

When the username is accepted, BotFather replies with your access token. It looks like `123456789:ABCdef...`. Copy it. Keep it private: anyone with this token can post as your bot.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Screenshot: BotFather reply containing the HTTP API token ]</div>

Back in InfluencerButler, open **API Integrations** and paste the token into the **Telegram Bot Token** field on the Telegram Bot card.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Screenshot: The Telegram Bot card with the token pasted into "Telegram Bot Token" ]</div>

## 3. Add the bot to your channel as an admin

Open the Telegram channel you want to post deals into, or create a new one. Open the channel's **Administrators** list, choose **Add Admin**, search for your bot by its username, and add it. Give it at least the **Post Messages** permission.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Screenshot: Channel "Administrators" screen with the bot added and "Post Messages" enabled ]</div>

## 4. Find your Channel / Chat ID

There are two formats:

- **Public channel**: use the public handle, for example `@gardenloversdeals`. This is the simplest option.
- **Private channel**: use the numeric ID, which starts with `-100`, for example `-1001234567890`. To find it, forward any message from the channel to a helper bot such as **@getidsbot**, which replies with the numeric ID.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Screenshot: The numeric chat ID returned by an ID-lookup bot, or the public @handle in the channel info ]</div>

## 5. Paste the values and test

Paste the handle or numeric ID into the **Channel / Chat ID** field, then click **Test Connection**. When everything is wired correctly the status turns green and reads "Connected".

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Screenshot: The Telegram card after a successful Test Connection, showing the green "Connected" badge ]</div>

## What gets posted

Once connected, Amazon Deals posts to this channel using Telegram's Bot API `sendPhoto` endpoint. Each post carries the product image from your deal row plus a caption built from your post composer template. Nothing is sent until you publish a post, so connecting the bot ahead of time is safe.

## Common gotchas

- **Test fails with "chat not found"**: the bot is not in the channel yet, or the handle / ID is wrong. Re-check step 3 and step 4.
- **Test fails with "not enough rights"**: the bot is in the channel but is not an admin, or lacks the Post Messages permission. Re-open the channel admins list and grant it.
- **Posts go nowhere after a username change**: if you renamed the channel's public handle, update the Channel / Chat ID field to match, then test again.
