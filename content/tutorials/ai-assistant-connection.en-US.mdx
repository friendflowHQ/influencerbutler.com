## What it is

The AI assistant connection lets an AI assistant you already use (Claude Code, Claude Desktop, Cursor and others) look at your Influencer Butler app and answer questions about it. You can ask things like "what ran today?", "does anything need me?" or "how did Message Brands do this week?" and get an answer based on your real activity.

It is read-only. The assistant can see butler status, which sites are signed in, schedules, run results and your earnings totals. It cannot start or stop a butler, post, send a message or change a setting. It never sees passwords, message text or customer details.

It is off until you turn it on, and it only works on the same computer the app runs on. Nothing goes through the internet.

## Turn it on

1. Open **Settings** in the app and find the **AI assistant connection** card
1. Switch on **Allow an AI assistant on this computer to connect**
1. The status line changes to "On. Ready on port ..." and three items appear: the **Address**, the **Key** and a **Claude Code setup line**
1. Leave the app running. The connection only works while the app is open

## Connect Claude Code

1. In the card, click **Copy** next to the **Claude Code setup line**
1. Open a terminal and paste the line, then press Enter
1. Start Claude Code and ask "what are my butlers doing right now?"

## Connect Claude Desktop or Cursor

1. In the card, click **Copy** next to **Claude Desktop or Cursor setup**
1. Paste it into the assistant's MCP settings file (for Claude Desktop, open Settings, then Developer, then Edit Config). If the file already has other servers, add only the influencer-butler entry
1. Restart the assistant. It runs with the Influencer Butler app itself, so there is nothing else to install

## Connect another assistant

Any assistant that supports MCP servers over HTTP can connect.

1. Add a new MCP server in that assistant's settings
1. Paste the **Address** from the card as the server address
1. Send the **Key** as a Bearer token in the Authorization header. Click **Show** if you need to read it, or **Copy** to paste it
1. If the assistant only supports local command-line servers, use a small bridge tool such as mcp-remote and point it at the same address and key

## What you can ask

The assistant gets these read-only tools:

- **Briefing**: one call for the morning picture: what is running, what is stuck, signed-out sites, earnings and what runs next. Start here for "what needs me today?"
- **Earnings**: yesterday, this month, a month forecast, your streak, a split by type and the last 14 days
- **Top earners**: the products that have earned the most
- **Sign-ins**: which sites the app is signed in to. A signed-out site is the most common reason a butler does nothing
- **Up next**: what is scheduled in the next 24 hours
- **List butlers** and **Butler status**: every butler with its state, or one in detail with its progress and last error
- **Needs attention**: only the butlers that stopped with an error
- **Run history**: a butler's recent runs and how each ended, so it can explain a failure
- **Activity**: runs, results and what is scheduled next, for the last 1 to 90 days

Try asking: "Give me my morning briefing", "Why did Message Brands fail last night?" or "What were my top earners this month?"

## Keep it safe

1. Treat the **Key** like a password. Anyone who has it can read your butler status from this computer
1. To cut off an assistant, click **Replace key**, then click again to confirm. The old key stops working at once
1. To turn the whole thing off, switch the toggle off. Nothing listens until you switch it on again

## Good to know

- After you replace the key, update it in your assistant, because the old one no longer works
- If the card says it could not start, another program may be using its port. Switch it off and on again, or restart the app
- It shows what the app knows on this computer. Butlers on another computer are not included
