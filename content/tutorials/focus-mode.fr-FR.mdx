## Ce que fait le Mode Concentration

InfluencerButler regroupe beaucoup de butlers dans une seule fenêtre. Cette puissance est le but, mais lors d'une journée chargée, un mur d'espaces de travail, de badges et de mouvement peut être beaucoup, surtout si vous avez un TDAH ou que vous êtes simplement tiré dans dix directions à la fois.

Le Mode Concentration est l'interrupteur du calme. Activez-le et le HUD se réduit à l'espace de travail devant vous, pour que vous puissiez terminer une chose avant que la suivante n'attrape votre attention. Il se combine avec quelques autres réglages pensés pour le calme, de sorte que toute l'app paraît moins distrayante, pas seulement un écran.

L'idée : garder votre attention sur la tâche que vous avez choisie, pas sur tout ce que l'app pourrait faire.

## Comment l'activer

Vous avez deux façons :

- **Clavier** : appuyez sur **Ctrl+.** depuis n'importe où dans l'app pour activer ou désactiver le Mode concentration.
- **Réglages** : ouvrez **Réglages > Apparence** et basculez l'interrupteur **Mode concentration**.

Les changements s'appliquent instantanément et persistent entre les lancements, donc une fois réglé à votre goût, il reste ainsi la prochaine fois que vous ouvrez Butler.

## Le reste des réglages pensés pour le calme

Le Mode concentration fonctionne mieux avec les autres options d'Apparence et de Performance :

- **Mouvement** : mettez-le sur **Réduit** (ou **Automatique (suivre l'OS)**) pour que les panneaux ne glissent pas, ne s'estompent pas et ne pulsent pas pendant que vous lisez. Si vous avez activé le mouvement réduit au niveau de l'OS, Automatique le respecte.
- **Thème** : choisissez **Clair**, **Sombre** ou **Automatique (suivre l'OS)**, ce qui est le plus reposant pour vos yeux.
- **Performance** : activez l'exécution des automatisations **une à la fois** pour que la fenêtre reste réactive sur les petites machines ou les machines virtuelles. Moins de choses en même temps, c'est moins de bruit visuel et une sensation plus fluide.
- **Langue** : l'anglais, l'espagnol et le français sont pris en charge, donc la vue plus calme se lit naturellement dans votre langue.

## Astuces

- Faites de **Ctrl+.** une habitude : tapez-le dès que vous vous asseyez pour travailler, et tapez-le à nouveau quand vous voulez retrouver toute la liste.
- Si l'app devient écrasante, utilisez le Mode concentration avec **Mouvement : Réduit**. Cette combinaison retire à la fois les panneaux supplémentaires et le mouvement.
- Sur un ordinateur portable ou une machine virtuelle, le réglage **une automatisation à la fois** est le plus grand gain pour garder la fenêtre fluide.
