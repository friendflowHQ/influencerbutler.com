## Ce que fait Mots-clés et filtres

Collage Butler compose des images multi-produits qui attirent l'attention à partir de vraies photos de produits Amazon. Cet écran est l'endroit où vous lui indiquez quoi y mettre. Les mots-clés et les filtres que vous définissez ici interrogent l'API Creators d'Amazon, et les produits renvoyés sont ceux que Collage Butler dispose dans votre collage.

Voyez-le comme la liste de courses. Le générateur gère la mise en page et le style ; ce panneau décide de la marchandise.

## Avant de commencer

Ouvrez Collage Butler dans les Paramètres et activez-le. Collage Butler est en version bêta, donc les commandes de cet écran restent verrouillées derrière une note "In Beta" tant que vous ne l'avez pas activé.

Vous n'avez besoin de rien d'autre ici. Les mots-clés et les filtres de prix sont des réglages facultatifs, donc un écran vide est un point de départ valable.

## Comment l'utiliser

1. Dans le menu de gauche, ouvrez **Collage Butler**, puis **Keywords & Filters** (Mots-clés et filtres).
2. Dans le champ **Keywords** (Mots-clés), saisissez les termes de recherche des produits souhaités, séparés par des virgules (par exemple : robes d'été, sacs de plage, sandales). Chaque terme est une recherche, donc quelques mots-clés ciblés valent souvent mieux qu'un seul trop large.
3. Dans **Category** (Catégorie, facultatif), indiquez un rayon pour affiner la recherche, comme Mode ou Maison. Laissez vide pour chercher partout.
4. Réglez **Minimum price** (Prix minimum) pour ignorer les produits moins chers que ce montant. Laissez vide pour ne pas fixer de plancher.
5. Réglez **Maximum price** (Prix maximum) pour ignorer les produits au-dessus de ce montant. Laissez vide pour ne pas fixer de plafond.
6. C'est toute la configuration dont cet écran a besoin. Tout ce que vous saisissez s'enregistre tout seul, alors rendez-vous dans l'onglet **AI Collage Generator** pour choisir une mise en page et composer le collage à partir de ces produits.

## Notes

- Collage Butler est en version bêta. L'écran peut évoluer au fil des améliorations, et les commandes restent verrouillées tant que vous n'avez pas activé Collage Butler dans les Paramètres.
- Chaque champ s'enregistre automatiquement pendant la saisie. Il n'y a pas de bouton d'enregistrement, et vos mots-clés et filtres vous attendent la prochaine fois que vous ouvrez l'écran.
- Les mots-clés et les filtres sont partagés par tous les collages que vous générez, donc les mettre à jour ici change ce que récupéreront les futurs collages.
- Les prix utilisent la devise de votre vitrine. Laissez le champ de prix vide plutôt que de saisir 0 si vous ne voulez pas de cette limite.
- Les produits proviennent de l'API Creators d'Amazon, donc les résultats dépendent de ce qui y est disponible pour vos termes. Si un collage revient peu fourni, essayez d'élargir un mot-clé ou de retirer les filtres de catégorie ou de prix.
