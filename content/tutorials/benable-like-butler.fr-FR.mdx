> **Gratuit pour toujours.** Benable Like Butler reste débloqué sur tous les comptes - essai, abonnement, expiré ou résilié. Aucune vérification de licence, aucun quota. C'est notre façon de vous garder dans le flux de travail.

## Ce que fait Benable Like Butler

Sur Benable (comme sur Amazon Creator et Instagram), rester dans le fil d'"activité récente" d'un autre créateur est l'un des moyens les moins coûteux de rester présent sans envoyer de DM. Benable Like Butler like les collections sur les profils que vous spécifiez - collections, éléments individuels à l'intérieur, ou les deux - selon une cadence.

L'objectif n'est pas de gonfler l'engagement. C'est de la réciprocité : si vous cherchez à grandir dans l'écosystème Benable, apparaître dans les notifications d'autres créateurs fait remarquer votre handle.

## Avant de commencer

- **Une session Benable active** dans Chrome - Benable Like Butler utilise votre session existante.
- **1-10 URLs de profils Benable** de créateurs dans votre niche. Les URLs ressemblent à `https://benable.com/<nom-de-profil>`.

## Votre première passe

1. Ouvrez **Benable Like Butler** sous Amazon Butler → Benable Butler (imbriqué sous le toggle Benable Butler).
2. Dans **Benable Profile URLs**, collez votre premier lien. Cliquez sur "+ Ajouter" pour en ajouter d'autres.
3. Dans **Paramètres d'exécution** :
   - **Max likes par run**: démarrez à 10 (la valeur par défaut). C'est par profil par run.
   - **Délai entre likes**: 8-12 secondes est sûr. Plus rapide que 5 secondes invite le rate-limit.
4. Cliquez sur **Start Benable Like Butler**.

Une fenêtre Chrome s'ouvre. Benable Like Butler parcourt chaque profil, trouve les collections et éléments éligibles, et clique sur "like" avec le délai configuré. La progression apparaît dans les KPI (**Total**, **Cette exécution**, plus le détail par profil).

## Réglages dans la durée

- **Max likes par run**: 10 par profil est prudent. Avec 5 profils ça fait 50 likes par run au total, bien en dessous du risque de rate-limit.
- **Délai**: gardez 8 secondes minimum. Plus rapide que 5 secondes, Benable commence à freiner.
- **Jours de cooldown** (dans les paramètres) - 7 par défaut. Benable Like Butler ne re-likera pas le même contenu dans cette fenêtre, gardant le signal d'activité authentique plutôt que spammy.
- **Quoi liker**: basculez entre liker seulement les collections de top-niveau vs descendre dans les éléments de chaque collection. Le like au niveau élément est un engagement plus profond mais consomme plus de votre quota quotidien.

## Planification

Benable Like Butler a un planificateur intégré :

1. Fixez une **heure de début** et un **intervalle de répétition** (par ex. toutes les 12 heures).
2. Cliquez sur **Activer la planification**.

Pendant que la planification est active, les panneaux liste de profils et paramètres d'exécution se verrouillent. Cliquez sur **Arrêter la planification** avant de les modifier. Une fois par jour ou toutes les 12 heures suffit - plus souvent risque le rate-limit et apporte rarement de la valeur.

## Où vont les données

L'historique de likes par profil est journalisé dans le cache preseed. Les KPI en haut montrent **Total** cumulé, les compteurs **Cette exécution** et le détail par profil ; les chips **Reset total** + **Reset run** les remettent à zéro indépendamment.

## Compagnon de Benable Butler

Cet espace s'associe naturellement à **Benable Butler** (celui qui construit et publie vos propres collections). Le pattern :

- **Benable Butler**: vous publiez vos propres collections curatées.
- **Benable Like Butler**: vous restez visible auprès d'autres créateurs de votre niche.
- **Benable Comment Butler**: vous commentez activement les collections des autres.

Les trois ensemble construisent une présence sur Benable sans avoir à passer des heures par jour sur la plateforme.

## Pièges courants

- **"Connexion Benable requise"**: votre session a expiré. Connectez-vous via la fenêtre Chrome ouverte, cliquez sur Reprendre.
- **Le planificateur paraît bloqué**: le panneau liste de profils est verrouillé tant qu'une planification est active. Cliquez sur Arrêter la planification, modifiez, relancez.
- **Un profil affiche 0 likes après un run**: généralement cooldownDays exclut encore tout sur ce profil. Attendez l'expiration ou baissez-le.
- **Les likes ne s'enregistrent pas**: l'URL du profil est incorrecte (404) ou votre session s'est déconnectée. Réouvrez l'URL dans Chrome manuellement pour vérifier.
