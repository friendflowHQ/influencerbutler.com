## Qué hace

Amazon Deals puede publicar las imágenes de tus productos y sus textos directamente en un canal de Telegram. Para configurarlo, conectas un bot de Telegram en el panel de **API Integrations**. Necesitas dos valores: un **token del bot** y el **ID del canal (chat)** en el que quieres publicar. Toda la configuración lleva unos cinco minutos. Aquí tienes la guía completa.

## 1. Crea un bot con BotFather

En Telegram, busca **@BotFather** (el bot oficial, tiene la marca azul de verificado) y abre un chat con él. Envía el comando `/newbot`. BotFather te pedirá un nombre visible y luego un nombre de usuario que debe terminar en `bot`, por ejemplo `gardenlovers_deals_bot`.

## 2. Copia el token del bot

Cuando se acepta el nombre de usuario, BotFather responde con tu token de acceso. Tiene este aspecto: `123456789:ABCdef...`. Cópialo. Mantenlo privado: cualquiera que tenga este token puede publicar como tu bot.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Captura: respuesta de BotFather con el token de la API HTTP ]</div>

De vuelta en InfluencerButler, abre **API Integrations** y pega el token en el campo **Telegram Bot Token** de la tarjeta del bot de Telegram.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Captura: la tarjeta del bot de Telegram con el token pegado en "Telegram Bot Token" ]</div>

## 3. Añade el bot a tu canal como administrador

Abre el canal de Telegram en el que quieres publicar ofertas, o crea uno nuevo. Abre la lista de **Administradores** del canal, elige **Añadir administrador**, busca tu bot por su nombre de usuario y añádelo. Dale al menos el permiso de **Publicar mensajes**.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Captura: pantalla de "Administradores" del canal con el bot añadido y "Publicar mensajes" activado ]</div>

## 4. Encuentra tu ID de canal / chat

Hay dos formatos:

- **Canal público**: usa el identificador público, por ejemplo `@gardenloversdeals`. Es la opción más sencilla.
- **Canal privado**: usa el ID numérico, que empieza por `-100`, por ejemplo `-1001234567890`. Para encontrarlo, reenvía cualquier mensaje del canal a un bot auxiliar como **@getidsbot**, que responde con el ID numérico.

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Captura: el ID numérico del chat devuelto por un bot de búsqueda de ID, o el @identificador público en la información del canal ]</div>

## 5. Pega los valores y prueba

Pega el identificador o el ID numérico en el campo **Channel / Chat ID** y luego haz clic en **Test Connection**. Cuando todo está bien configurado, el estado se pone verde y muestra "Connected".

<div className="help-shot-placeholder" style={{ border: "2px dashed var(--brand, #f97316)", borderRadius: "8px", padding: "18px", margin: "12px 0", textAlign: "center", color: "var(--muted, #666)", fontSize: "13px" }}>[ Captura: la tarjeta de Telegram tras una conexión correcta, mostrando la insignia verde "Connected" ]</div>

## Qué se publica

Una vez conectado, Amazon Deals publica en este canal usando el endpoint `sendPhoto` de la Bot API de Telegram. Cada publicación lleva la imagen del producto de tu fila de oferta más un texto creado a partir de la plantilla de tu compositor de publicaciones. No se envía nada hasta que publicas, así que conectar el bot con antelación es seguro.

## Problemas frecuentes

- **La prueba falla con "chat not found"**: el bot todavía no está en el canal, o el identificador / ID es incorrecto. Revisa el paso 3 y el paso 4.
- **La prueba falla con "not enough rights"**: el bot está en el canal pero no es administrador, o le falta el permiso de Publicar mensajes. Vuelve a abrir la lista de administradores del canal y concédeselo.
- **Las publicaciones no llegan tras cambiar el nombre de usuario**: si has cambiado el identificador público del canal, actualiza el campo Channel / Chat ID para que coincida y vuelve a probar.
