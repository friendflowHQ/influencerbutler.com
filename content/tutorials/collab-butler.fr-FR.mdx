## Ce que fait Collab Butler

Une fois que vous travaillez avec des marques à n'importe quelle échelle, il vous faut un endroit pour suivre chaque deal qui ne soit pas votre boîte de réception. Collab Butler est cet endroit - un tableau style Kanban où chaque carte représente une collaboration de marque et avance entre les étapes au fil du deal.

Il se distingue de **Pitch Butler** (qui suit le pipeline pré-deal : prospect → pitched → replied → negotiating → closed). Collab Butler prend le relais *après* la fermeture du deal : post-production, publié, payé, terminé. Ensemble, les deux couvrent tout le cycle de vie.

## Avant de commencer

Rien d'obligatoire - Collab Butler n'importe ni n'automatise rien. C'est un espace de pur tracking. Vous ajoutez des cartes à la main au fur et à mesure des deals.

Optionnel : une habitude d'**Exporter JSON**. Il y a un bouton **Delete All** et il est littéral et irréversible. Exportez avant tout gros nettoyage.

## Votre première collab

1. Ouvrez **Collab Butler** dans la navigation.
2. Cliquez sur **New Collab**. Une nouvelle carte apparaît.
3. Remplissez :
   - **Nom de marque**: obligatoire.
   - **Étape**: choisissez parmi un set par défaut (Pitched, In Production, Posted, Awaiting Payment, Paid, Completed). Vous pouvez renommer les étapes globalement dans les paramètres.
   - **Date limite**: la date à laquelle le contenu est dû. Utilisée pour filtrer "qu'est-ce qui est dû cette semaine".
   - **Paiement**: le tarif convenu (unique ou par livrable).
   - **Notes**: libre. Stockez ici l'email du contact marque, le brief, les liens vers le contenu draft.
4. Faites glisser les **tags de workflow** depuis l'étagère à droite sur la carte pour ajouter du signal type-de-contenu : "Reel publié", "Story publiée", "En attente d'approbation", etc. Les tags sont des modificateurs visuels par-dessus l'étape ; vous pouvez en avoir plusieurs par carte.

## Filtrage et vues

La barre de filtres en haut découpe le tableau par :

- **Étape**: affiche seulement les cartes dans une étape. Utile pour "qu'est-ce qui est publié mais pas encore payé" ou "qu'est-ce qui est pitché mais pas commencé".
- **Marque**: affiche seulement les cartes pour une marque (si vous avez fait plusieurs deals avec elle).
- **Tag**: affiche seulement les cartes avec un tag de workflow précis.
- **Recherche libre**: sur nom de marque + notes.
- **Fenêtre d'échéance**: dans les X prochains jours. Utile pour la planification hebdo.

## Vues, édition rapide et actions groupées

- **Vue Tableau ou Liste**: utilisez le sélecteur **Tableau / Liste** dans la barre d'outils. Tableau, ce sont les colonnes Kanban classiques. Liste est un tableau compact (une ligne par collab) avec un menu déroulant d'étape en ligne, les tags et l'échéance. La vue Liste fonctionne entièrement au clic, vous n'avez donc jamais à glisser. Votre choix est mémorisé d'une session à l'autre.
- **Changer d'étape sans glisser**: chaque carte et chaque ligne de liste a un petit **menu déroulant d'étape**. Choisissez-y une étape pour déplacer la collab. Glisser les cartes entre colonnes fonctionne toujours si vous préférez.
- **Édition rapide**: survolez une carte et cliquez sur le petit bouton crayon dans son coin pour ouvrir un panneau d'édition rapide (marque, échéance, étape, tags, notes) sans quitter le tableau. Le panneau ne s'ouvre qu'au clic sur le crayon, il n'apparaît donc plus juste en déplaçant la souris sur le tableau.
- **Sélectionner plusieurs collabs**: cliquez sur **Sélectionner** dans la barre d'outils pour afficher les cases à cocher. Cochez les cartes voulues (ou **Tout sélectionner**), puis utilisez la barre d'actions groupées pour changer leur étape, ajouter un tag ou les archiver d'un coup. Cliquez sur **Terminé** pour quitter le mode sélection.

## Export

Deux formats :

- **Export JSON**: le backup structuré complet. À utiliser avant tout nettoyage ; le fichier peut être ré-importé dans le même espace plus tard.
- **Export CSV**: une version aplatie pour les impôts, la compta, les rapports à un manager. Chaque ligne est une collab avec étape, paiement, échéance, statut de paiement.

Les exports JSON sont sans perte. Les exports CSV aplatissent les tags de workflow dans une cellule séparée par virgules.

## Réglages dans la durée

- **Liste d'étapes**: les étapes par défaut couvrent la plupart des flux. Personnalisez dans les paramètres si votre process diffère (par ex. ajoutez "UGC livré" entre Posted et Paid).
- **Tags de workflow**: même idée. L'étagère par défaut est un set de départ raisonnable ; ajoutez les vôtres (par ex. "Édition due", "Marque en revue").
- **Paiement par carte**: soyez cohérent sur la devise et avant/après taxes. Collab Butler ne valide pas ; les totaux dans les exports comptent sur votre propreté.

## Où vont les données

Les cartes Collab vivent dans le cache preseed. L'état complet du tableau entre dans le flux de backup régulier de l'app.

## Pièges courants

- **Delete All supprime réellement**: exportez en JSON d'abord. Si vous avez déjà cliqué sans export, le backup app-niveau précédent peut avoir une copie dans `{userData}/InfluencerButler/backups/` - vérifiez avant de supposer que les données sont perdues.
- **Le drag-to-stage ne se déclenche pas**: assurez-vous de déposer la carte sur le header de colonne d'étape, pas sur les cartes empilées en dessous. Si glisser est pénible, utilisez le **menu déroulant d'étape** par carte ou passez en **vue Liste**.
- **Export CSV avec champs manquants**: le CSV aplatit les structures imbriquées. Utilisez JSON s'il vous faut l'enregistrement complet.
- **Deux collabs avec la même marque**: Collab Butler ne dédoublonne pas ; une marque peut avoir plusieurs cartes (une par deal). Utilisez le filtre de marque pour les voir côte à côte.
