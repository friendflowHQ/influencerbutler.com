## What Data Refresh Butler does

Data Refresh Butler is the scheduler for the two Amazon catalogs that everything else depends on:

- The **Creator Connections (CC) campaign catalog** - every active campaign visible to your storefront.
- The **SPCC catalog** - Sponsored Products for Creators commission rates.

Daily Commission Butler, Goldmine Butler, Ads Goldmine Butler, Earnings Intelligence, and Deals Influencer Butler all read from these. If they're stale, those workspaces make decisions on old data. Data Refresh Butler is where you set the cadence.

It has no runner of its own - it just configures and triggers the catalog
refresh on the schedule you pick. This is the **only** place catalog refresh and
scheduling live: CC Check no longer downloads catalogs itself, it just checks
ASINs against whatever these refreshes produce.

## Before you start

- **CC Storefront ID** set in the topbar - without it, cc-check has nothing to download against.
- Optionally: a **Creators API key** in **API Integrations** for the SPCC half. The CC half doesn't need the API.

## First-run setup (the easy path)

The default setup couples refreshes to your Deals Influencer Butler search cadence: CC + SPCC re-download **1 hour before each scheduled Deals Influencer Butler search**. If you run Deals Influencer Butler, this is the right setup - you don't touch anything else.

1. Open **Data Refresh Butler** under Amazon Butler.
2. Confirm the coupling chip near the top reads: *"Refreshes 1h before each scheduled Deals Influencer Butler search."*
3. Done.

## Manual cadence (if you don't use Deals Influencer Butler)

If Deals Influencer Butler isn't running on a schedule, click **Break link** on the coupling chip and set a manual cadence:

1. In **Refresh schedule**, the default is **Custom (daily at 04:00)**. That's plenty for most users; a once-a-day overnight refresh keeps catalogs fresh without hammering Amazon. The hourly presets are aggressive and rarely needed.
2. **Refresh at this time** lets you anchor the daily refresh to a clock time (defaults to 4:00 AM).
3. Leave **Include SPCC commission refresh** on (the default) so each scheduled refresh also pulls the SPCC commission catalog. Turn it off to refresh only the Creator Connections catalog.
4. In **Refresh catalogue if older than**, leave 12h as the freshness window. This skips a costly 5-minute redownload if the cached catalog is still recent enough.

## Splitting CC and SPCC cadences (advanced)

Commission rates (SPCC) change more often than campaign listings (CC), so you can refresh SPCC faster than CC. Toggle **Advanced - split SPCC refresh onto a faster cadence**:

- **Creator Connections (full)**: 24h is fine for most users.
- **SPCC commissions only**: 1h or 3h if you watch margins closely; 6h otherwise.

The split is opt-in - without it, both refresh on the same cadence.

## Running on demand

The CC and SPCC cards each show an explicit **last refresh** date and time (e.g. "May 30, 2026, 4:02 AM"), so you can tell at a glance how current the data is. The **Current status** card shows the last and next refresh times for each catalog, plus three action buttons:

- **Run now** under CC - refreshes just the CC catalog.
- **Run now** under SPCC - refreshes just the SPCC catalog.
- **Refresh both**: runs both in sequence.

Useful before a manual Deals Influencer Butler search or before reviewing Daily Commission Butler candidates.

## Common gotchas

- **"Refresh failed: no storefront"**: set your CC Storefront ID in the topbar first.
- **The coupling chip is missing**: Deals Influencer Butler doesn't have an active schedule, so there's nothing to couple to. Set a Deals Influencer Butler schedule first, or use manual cadence.
- **Catalog stays empty after a refresh**: usually means the underlying cc-check runner hit an Amazon sign-in prompt. Open cc-check, sign in, and rerun.
