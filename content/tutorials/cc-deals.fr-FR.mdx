## Ce que fait Offres de campagnes

Offres de campagnes se trouve sous CC Check et répond à une question: quels
produits des campagnes Creator Connections auxquelles vous participez sont **en
promotion en ce moment**? Au lieu de parcourir un catalogue d'offres générique,
vous ne voyez que les articles liés aux campagnes que vous avez rejointes, avec
la remise, le prix promotionnel, le prix d'origine, la date de fin de l'offre et
votre taux de commission, le tout dans un tableau trié par remise décroissante.

## D'où viennent les données d'offres

Pas besoin de chercher les prix. CC Check interroge déjà chacun de vos ASIN via
l'API Creators d'Amazon, qui renvoie les prix promotionnels actuels et les
détails de l'offre. Offres de campagnes réutilise ces mêmes données et n'affiche
que les articles réellement remisés. Aucun navigateur ne s'ouvre pour cela;
c'est une requête API rapide.

## Actualiser la liste

La liste reste à jour de trois façons:

1. Bouton **Actualiser les offres**: revérifie les prix promotionnels actuels
   des ASIN de vos campagnes à la demande. Rapide, sans navigateur.
2. **Automatique**: chaque fois que vous lancez **Vérifier les ASIN** dans CC
   Check, les données d'offres collectées arrivent directement dans Offres de
   campagnes.
3. **Planification**: définissez une heure de début et un intervalle de
   répétition pour actualiser la liste en arrière-plan (par exemple, une fois
   par jour). L'application doit rester ouverte pour que les actualisations
   planifiées se déclenchent.

## Acceptées uniquement, ou aussi disponibles

Par défaut, le tableau n'affiche que les campagnes que vous avez **acceptées**,
les offres les plus pertinentes pour vous. Activez **Inclure les disponibles
(pas encore acceptées)** pour voir aussi les articles en promotion des campagnes
qui vous sont proposées mais que vous n'avez pas encore rejointes, un moyen
rapide de repérer un produit remisé pour lequel il vaut la peine d'accepter une
campagne.

## Repérez les produits qui paient un bonus social

Certaines marques paient un taux plus élevé quand vous publiez un produit sur vos
réseaux. Amazon ne partage pas cela dans les données d'offres, la colonne **Bonus
social** vous permet donc de le marquer vous-même : cochez la case sur la ligne
d'un produit et ajoutez une courte note (par exemple, "+3% sur IG"). Vos marques
sont enregistrées automatiquement et conservées entre les actualisations, vous
savez ainsi toujours quels produits en promotion méritent une publication
supplémentaire.

## Points d'attention

- **Tableau vide**: si vous n'avez encore accepté aucune campagne, ou si rien
  dans vos campagnes n'est remisé pour l'instant, le tableau est vide. Cliquez
  sur **Actualiser les offres**, ou activez **Inclure les disponibles** pour
  élargir la recherche.
- **Les prix semblent obsolètes**: les offres changent vite. Cliquez sur
  **Actualiser les offres** pour les plus récentes, ou activez la planification
  pour qu'elle se mette à jour seule.
