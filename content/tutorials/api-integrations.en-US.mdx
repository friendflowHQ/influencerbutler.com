## What API Integrations does

A lot of workspaces in InfluencerButler talk to external APIs: Amazon's Creators API for product metadata, OpenAI for content generation, YouTube for uploads, Levanta/Archer/Logie/Geniuslink/Linktw.in for affiliate routing, and so on. Instead of asking for each key inside each workspace, API Integrations is the single panel where you paste them once and they're available everywhere.

It also handles **affiliate routing** - the logic that decides which provider's link generates for any given product, optimizing for the highest commission rate when multiple providers cover the same ASIN.

## Before you start

Nothing required - but each integration is independent, so you can add them one at a time as you wire up new workspaces. Common first integrations:

- **Amazon Creators API**: needed by Storefront Butler, Daily Commission Butler, Voiceover Butler, anything that reads product details.
- **OpenAI**: needed by AI Content Butler, Voiceover Butler, Benable Butler, Comment Butler. Need a key? See [Set up the OpenAI API (it is not ChatGPT)](/help/tutorials/openai-api-setup): it is not the same as a ChatGPT subscription.
- **Your deeplink provider**: needed once you want shortened/tracked affiliate links instead of raw Amazon URLs.

## Adding an integration

The panel is organized by section. Each section has:

- A **paste-key field** - where you put the credential.
- A **Test Connection** button - fires a request against the provider's API to verify the key. Most providers get a read-only check; GeniusLink's test also creates one real short link, so a green check proves link creation works, and the minted link is shown so you can open it and see which country store your group routes to.
- A **status badge** - green when verified, red when invalid, grey when untested.

To add: open the section, paste the key, click Test Connection. If green, you're done - every workspace that uses this provider will pick the key up automatically.

The full provider list:

- **Amazon Creators API**: primary product-data source.
- **Amazon Associates**: your affiliate tag (one per marketplace).
- **OpenAI**: content generation.
- **YouTube OAuth**: uploads + comments.
- **Pinterest OAuth**: uploads (when Pinterest Butler ships).
- **Levanta**: brand network.
- **Archer**: affiliate network.
- **Logie**: affiliate network.
- **Mavely**: multi-brand network for non-Amazon deals (Walmart, Target, and a large brand catalog). Sign in instead of pasting a key. See the Mavely section below.
- **Benable**: referral link.
- **Deeplink providers**: Influencer Butler (branded links with a built-in click dashboard), PostTap, Linktw.in, URLGenius, Geniuslink, Mavely. Choose one as primary.

## Affiliate routing

The bottom section of the panel: **Pick the highest-commission provider for each product**. When this toggle is on:

1. Every product link generated anywhere in the app routes through this logic.
2. The logic checks each connected provider for their commission rate on that specific ASIN.
3. The link is generated through whichever pays the most.

Below the toggle is a checkbox grid of which providers participate in routing - uncheck a provider to exclude it even when connected (useful if you've connected a provider for testing but don't want it used in production yet).

Levanta / Archer / Logie attribution links are special-cased: their links route through whatever **deeplink provider** you have set as primary, regardless of routing toggles. That's because their attribution mechanism is independent of the link host.

## Mavely (sign in, no API key)

Mavely is different from the other affiliate networks: it has no API key to paste. It monetizes **non-Amazon** deals, so it's how you earn commission on Walmart, Target, and its large brand catalog straight from the deal poster.

On the Mavely card:

1. Click **Sign in to Mavely**. A normal Chrome window opens on the Mavely creators site.
2. Log in with your Mavely account, then close that window.
3. Back in the panel, click **Check status**. It should read "Signed in to Mavely."

Once you're signed in, you have two ways to use it:

- **As your deeplink provider**: pick **Mavely** in DeepLink Routing. Now when Deals Influencer Butler posts a Walmart or Target deal, the link is a commission-earning Mavely link automatically.
- **One-off links**: paste any product URL into the Mavely card's Product URL box and click **Create Link** to get a single Mavely link on the spot. The Chrome extension's link button does the same for non-Amazon pages.

Your Amazon links are untouched by this: only non-Amazon retailers route through Mavely. If you ever sign out of Mavely, links quietly fall back to the plain product URL so a post never goes out broken.

## Test on startup

A toggle in the panel header: **Test all integrations on app startup**. When on, every connected provider gets a Test Connection on launch, and the badges update accordingly.

**Recommended off after the first few launches.** It adds 30-60 seconds to startup and most users only need to know an integration broke when a workspace fails - not pre-emptively at every launch.

## Tuning over time

- **Don't add providers you don't need.** Each connected provider is one more thing that can break and one more API key to rotate. Add as needed.
- **Rotate keys yearly.** Most APIs let you generate a fresh key with the old one still valid for a grace period. Generate the new one, paste here, test, then revoke the old.
- **The affiliate-routing toggle pays for itself within a week.** If you're connected to multiple providers, having it on is almost always a net commission gain.

## Where the data goes

API keys are stored encrypted in `{userData}/InfluencerButler/secure-store/`. The store is AES-256-GCM with a key derived from your machine - keys aren't portable across machines without re-entering them.

## Common gotchas

- **Test Connection fails after a previously-working setup**: the provider rotated, revoked, or rate-limited the key. The topbar shows an "API Health" badge when this happens. Re-issue the key from the provider's dashboard, paste here, re-test.
- **Creators API test says "failed" but Amazon shows it active**: almost always a marketplace mismatch. Set the Marketplace dropdown to the region where you created your API credentials. A US credential tested against a UK or AU marketplace (or an international credential left on the amazon.com default) will not pass. The app now detects this and tells you which region your credentials belong to.
- **Creators API Partner Tag rejected**: that field needs your Amazon Associates tracking ID (like yourtag-20), not your storefront ID.
- **Creators API credential fields look blank after a restart**: that is expected. Saved keys are hidden for security. Just pick your marketplace and press Test Connection. You do not need to re-paste them.
- **A brand-new Creators API key fails right after you create it**: newly issued keys can take up to 24 hours to activate on Amazon's side. Wait and re-test.
- **OpenAI key tested green but generation fails**: different OpenAI products use different rate limits. A key valid for completions may hit a billing/quota issue on a specific model. Check the OpenAI dashboard's billing tab.
- **YouTube OAuth expires unexpectedly**: Google rotates OAuth tokens roughly annually. Re-run the YouTube Butler Setup Wizard to refresh.
- **Affiliate routing picked the wrong provider**: usually means the wrong provider was checked. Open the routing section and verify the participating-providers checkboxes.

## In the Chrome extension too

The free [Influencer Butler Chrome extension](/help/tutorials/extension) now has its own API Integrations panel, so you can connect the same providers without the desktop app. Open the extension popup and click the **gear icon** in the top-right to reach it. You get the same flow: paste a key, **Test Connection**, watch the badge turn green, and a **Run all saved tests** button plus a **test-on-startup** toggle. It covers OpenAI, the Amazon Creators API, per-country Associates tags, the deeplink providers, and the affiliate networks, with the same affiliate-routing and primary-deeplink controls.

The important difference is where the keys live. In the extension, your keys stay on your device, encrypted in the browser's local storage, and are sent only to each provider's own API (for example OpenAI's key only ever goes to OpenAI). They never touch Influencer Butler servers. Because access to each provider is granted on demand, the first time you test or save a provider Chrome asks you to allow the extension to reach that provider's site.

Once connected, the extension uses them while you browse Amazon: a **Copy my link** button on any product builds your affiliate/deeplink, and (when OpenAI is connected and tested) a **Draft caption** button writes a quick post for you.

Note: live Test Connection currently makes a real read-only call for OpenAI and the Amazon Creators API; the deeplink providers and affiliate networks validate your saved configuration, with live pings added as each provider's endpoint is confirmed.

## Amazon native deep link

At the top of **DeepLink Routing** is the **Amazon native deep link** switch, on by default. When it's on, every Amazon product link your tools build opens straight in the Amazon app on a phone instead of a mobile browser, which is a smoother tap-to-buy for your shoppers. It's separate from the provider list below: the provider picks the redirect/shortener, while this switch controls the in-app open. Turn it off if you'd rather post plain browser links.

One thing to know: for the link to actually open the app, your Amazon Associates account also needs "Deep linking enabled" in SiteStripe. The switch adds the right link format; your account setting is what tells Amazon to honor it.

## Per-country affiliate tags

Under **DeepLink Routing** there's a collapsible **Per-country affiliate tags** list. Most of these fill in for you: when you run the Storefront ID check in **Settings**, it reads the associate tags on your Amazon account and populates the matching countries automatically. Re-run the check any time to refresh them. You can still type a tag into any country by hand to override it, and a tag you type is kept. Your US tag defaults to your CC Storefront ID; leave a country blank to skip it.

These tags power the **Marketplace links** options in Deals Influencer Butler. A tag is what makes a commission track in that country, so a foreign link only gets posted when you've added its tag.

## Link Performance dashboard

**Influencer Butler** is also a deeplink provider in its own right. Pick it under **DeepLink Routing** and every link your tools build becomes a branded `links.influencerbutler.com` short link that you own. It's included free on every plan, so just sign in and pick it.

Right below the provider list is the **Link Performance** panel. Open it to see how your audience is clicking: total clicks, a day-by-day trend, your top links, and a breakdown by country, device, and referrer. Pick a date range (7, 30, or 90 days) and the numbers update. Because Amazon does not report earnings per outgoing link, these are click metrics, not revenue.

Links are grouped per product, so re-posting the same item keeps its clicks together instead of splitting them across many short links.

## Link Health

A branded link is a redirect you own, so what you post points at the short link, not the product. That is what makes **Link Health** possible. Open the **Link Health** panel just below Link Performance and press **Check now**. Influencer Butler looks up every branded link's product on Amazon and flags any that are out of stock or removed from the catalog. Your audience never sees a dead link, but a sold-out product still costs you the sale, so this is the panel that finds those before they quietly drain your earnings.

For each broken link you get a suggested replacement product (found with the same matching Retag Butler uses), or you can paste your own Amazon URL. Press **Repoint** and Influencer Butler updates the link's destination on the backend. Because everyone who clicks goes through the short link, every copy you already posted, across every platform, instantly starts pointing at the live product. You do not re-post anything.

Turn on **Check automatically** to run this in the background on a daily or weekly schedule, so you are told the moment a link goes bad. Products in a marketplace you have not connected API credentials for are marked "not checked" rather than broken.
