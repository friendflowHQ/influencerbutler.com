## Qué hace API Integrations

Muchos espacios en InfluencerButler hablan con APIs externas: la Creators API de Amazon para metadatos de producto, OpenAI para generación de contenido, YouTube para subidas, Levanta/Archer/Logie/Geniuslink/Linktw.in para enrutamiento de afiliados, etc. En vez de pedir cada clave dentro de cada espacio, API Integrations es el panel único donde las pegas una vez y quedan disponibles en todas partes.

También maneja el **enrutamiento de afiliados** - la lógica que decide por qué proveedor se genera el enlace para cualquier producto, optimizando para la tasa de comisión más alta cuando varios proveedores cubren el mismo ASIN.

## Antes de empezar

Nada obligatorio - pero cada integración es independiente, así que las puedes añadir una a una a medida que conectas espacios nuevos. Integraciones habituales para empezar:

- **Amazon Creators API**: la necesitan Storefront Butler, Daily Commission Butler, Voiceover Butler, todo lo que lee detalles de producto.
- **OpenAI**: la necesitan los butlers con IA: Generador de palabras clave con IA, Voiceover Butler, Benable Butler, Benable Comment Butler, Benable List Optimize, Facebook Group Builder y las funciones de IA opcionales de Deal Posting, Social Posting Butler, YouTube Butler, Video Reload Butler, Orders Butler y Eliminar publicaciones y comentarios. Pagas a OpenAI directamente por lo que usas (normalmente céntimos), no a Influencer Butler, y una suscripción a ChatGPT no funciona. Mira [Configura la API de OpenAI (no es ChatGPT)](/help/tutorials/openai-api-setup) para ver la lista completa de herramientas que necesitan clave y qué está incluido sin ella (el AI Assistant no necesita clave).
- **Otras claves de IA y datos**: el estilo de título con IA de Photo Reload y Video Reload usa una clave de Anthropic, y Keepa, Fal.ai e Ideogram usan cada uno su propia clave, todas se añaden en este panel.
- **Tu proveedor de deeplinks**: la necesitas en cuanto quieras enlaces de afiliado acortados/trackeados en vez de URLs crudas de Amazon.

## Añadir una integración

El panel está organizado por sección. Cada sección tiene:

- Un **campo para pegar la clave** - donde metes la credencial.
- Un botón **Test Connection** - dispara una petición contra la API del proveedor para verificar la clave. La mayoría de proveedores reciben una comprobación de sólo lectura; el test de GeniusLink además crea un enlace corto real, así que un check verde demuestra que la creación de enlaces funciona, y el enlace creado se muestra para que puedas abrirlo y ver a qué tienda de país redirige tu grupo.
- Un **badge de estado** - verde cuando se verifica, rojo si es inválida, gris si no se ha probado.

Para añadir: abre la sección, pega la clave, pulsa Test Connection. Si está verde, listo - cada espacio que use este proveedor cogerá la clave automáticamente.

Lista completa de proveedores:

- **Amazon Creators API**: fuente principal de datos de producto.
- **Amazon Associates**: tu tag de afiliado (uno por marketplace).
- **OpenAI**: generación de contenido.
- **YouTube OAuth**: subidas + comentarios.
- **Pinterest OAuth**: subidas (cuando Pinterest Butler salga).
- **Levanta**: red de marcas.
- **Archer**: red de afiliados.
- **Logie**: red de afiliados.
- **Mavely**: red multimarca para ofertas fuera de Amazon (Walmart, Target y un amplio catálogo de marcas). Inicias sesión en vez de pegar una clave, desde su propia tarjeta en Deeplink Butler > Ajustes, no en esta página. Consulta el [tutorial de Deeplink Butler](/help/tutorials/link-butler).
- **Benable**: enlace de referido.
- **Proveedores de deeplinks**: Influencer Butler (enlaces de marca con un panel de clics integrado), PostTap, Linktw.in, URLGenius, Geniuslink, Mavely. Elige uno como principal.

## Credenciales de respaldo de la Creator API

Amazon no desbloquea la Creator API hasta que tu cuenta ha hecho suficientes ventas que cualifiquen, así que un influencer recién llegado puede crear credenciales que parecen correctas pero fallan en Test Connection con un error de elegibilidad (HTTP 403). No hace falta esperar: Influencer Butler puede prestarte sus propias credenciales de respaldo.

Cuando un test de la Creators API falla con ese bloqueo de elegibilidad, aparece un botón bajo el resultado: **Usar las credenciales de respaldo de Influencer Butler**. Con un clic, todos los espacios de trabajo que leen datos de producto empiezan a funcionar de inmediato con el juego de respaldo. Antes de pulsarlo, revisa tu Partner Tag: debe ser tu ID de seguimiento de Associates (como tutag-20), no un ID de escaparate, porque un tag incorrecto produce exactamente el mismo error.

Durante el recorrido de configuración inicial no tienes que buscar ese botón tú mismo: el recorrido detecta el bloqueo de elegibilidad en el momento en que ocurre y te ofrece las credenciales de respaldo ahí mismo, con una explicación sencilla de que es una clave compartida temporal, no un cambio de tu propio ID de seguimiento de Amazon. Pegar tus propias credenciales durante el recorrido también prueba la conexión por ti; no necesitas pulsar Test Connection.

Mientras el respaldo está activo, el panel muestra el distintivo **Credenciales de respaldo activas**. Tus propias credenciales siguen guardadas y la aplicación las vuelve a probar en silencio una vez al día. En cuanto Amazon desbloquee tu cuenta, la aplicación vuelve automáticamente a tus credenciales y te avisa con una notificación. También puedes pulsar **Dejar de usar el respaldo** en cualquier momento, o repetir Test Connection tú mismo; un test superado te devuelve a las tuyas al instante.

Unas dos semanas después de empezar a usar el respaldo aparece un aviso pidiéndote que cambies a tus propias credenciales ahora que probablemente ya cualificas, con un botón **Muéstrame cómo** que señala la tarjeta de la Creators API. Si lo cierras, vuelve a aparecer cada pocos días hasta que tus propias credenciales funcionen o desactives el respaldo.

El respaldo está disponible para cualquier usuario con sesión iniciada, incluidas las pruebas gratuitas. Las consultas de producto hechas con él usan la cuenta de Influencer Butler; tus enlaces y tags de afiliado no se tocan, así que tus comisiones siguen siendo tuyas.

## Enrutamiento de afiliados

La sección inferior del panel: **Elige el proveedor con la mayor comisión para cada producto**. Cuando este toggle está activado:

1. Cada enlace de producto generado en cualquier sitio de la app se enruta por esta lógica.
2. La lógica consulta a cada proveedor conectado por su tasa de comisión para ese ASIN concreto.
3. El enlace se genera por el que más pague.

Debajo del toggle hay una rejilla de checkboxes de qué proveedores participan en el enrutamiento - desmarca uno para excluirlo aunque esté conectado (útil si has conectado un proveedor para pruebas pero aún no quieres usarlo en producción).

Los enlaces de atribución de Levanta / Archer / Logie son un caso especial: se enrutan por el **proveedor de deeplinks** que tengas como principal, sin importar los toggles de enrutamiento. Eso es porque su mecanismo de atribución es independiente del host del enlace.

## Mavely (inicia sesión, sin clave de API)

Mavely es distinto de las otras redes de afiliados: no tiene clave de API que pegar, y su tarjeta ya no está en esta página. Consulta [Deeplink Butler](/help/tutorials/link-butler) para los pasos de inicio de sesión y cómo enrutar Walmart, Target y su amplio catálogo de marcas a través de él.

## Test al arrancar

Un toggle en la cabecera del panel: **Probar todas las integraciones al arrancar la app**. Activado, cada proveedor conectado recibe un Test Connection al arrancar y los badges se actualizan.

**Recomendado desactivado después de los primeros arranques.** Añade 30-60 segundos al arranque y la mayoría de usuarios sólo necesita saber que una integración rompió cuando un espacio falla - no preventivamente en cada arranque.

## Ajustes con el tiempo

- **No añadas proveedores que no necesites.** Cada proveedor conectado es una cosa más que puede romperse y una clave más que rotar. Añade según haga falta.
- **Rota las claves anualmente.** La mayoría de APIs te dejan generar una clave fresca con la vieja aún válida un periodo de gracia. Genera la nueva, pega aquí, prueba, luego revoca la vieja.
- **El toggle de enrutamiento de afiliados se paga solo en una semana.** Si estás conectado a varios proveedores, tenerlo activado casi siempre supone una ganancia neta de comisión.

## Dónde van los datos

Las claves de API se guardan cifradas en `{userData}/InfluencerButler/secure-store/`. El almacén es AES-256-GCM con una clave derivada de tu máquina - las claves no son portables entre máquinas sin volverlas a introducir.

## Tropiezos comunes

- **Ya no encuentras API Integrations en el menú de la izquierda**: la página cambió de nombre. Ahora se llama **Claves de IA y datos** en el menú de la izquierda. Es la misma página con otro nombre; guarda las claves compartidas de OpenAI, Anthropic, Keepa, Fal.ai e Ideogram. Cada clave de un proveedor concreto (GeniusLink, Mavely, la API de Creadores, Levanta y el resto) vive en la pestaña **Configuración** de su propio butler, como se describe en el punto siguiente.
- **No encuentras la sección de la API de Creadores de Amazon en esta página**: se ha movido. Cada integración de terceros vive ahora en el butler que la usa, y esta página conserva las claves compartidas de IA y datos (OpenAI, Keepa, Fal.ai, Ideogram). La API de Creadores de Amazon y tu ID de tienda están en **Amazon Butler**, luego **Configuración**. Mavely, el enrutamiento de enlaces profundos, Geniuslink, URLGenius, Linktw.in, Archer, PostTap, el enrutamiento de afiliados y las etiquetas por país están en Deeplink Butler, luego Configuración. Levanta está en Levanta Butler, luego Configuración. Tus claves guardadas se conservaron, así que no hay que volver a pegar nada.
- **El error de elegibilidad aparece en pantalla pero no hay botón de credenciales de respaldo debajo**: pulsa **Probar conexión** una vez y la oferta aparece con el resultado nuevo. Las versiones de la app anteriores a la 1.0.80 volvían a mostrar el error guardado tras reiniciar sin traer de vuelta el botón.
- **Test Connection falla en un setup que antes funcionaba**: el proveedor rotó, revocó o rate-limitó la clave. La barra superior muestra un badge "API Health" cuando esto pasa. Vuelve a emitir la clave en el dashboard del proveedor, pega aquí, re-prueba.
- **La prueba de la Creators API dice "failed" pero Amazon la muestra activa**: casi siempre es un desajuste de marketplace. Ajusta el desplegable Marketplace a la región donde creaste tus credenciales de API. Una credencial de US probada contra un marketplace de UK o AU (o una credencial internacional dejada en el amazon.com por defecto) no pasará. La app ahora lo detecta y te dice a qué región pertenecen tus credenciales.
- **¿Necesitas credenciales de Creators API separadas para Amazon.ca o Amazon.com.mx?**: No. Amazon.com, Amazon.ca y Amazon.com.mx están todas en el grupo de Norteamérica de Amazon y comparten un mismo juego de credenciales de la Creators API, así que tu conexión de EE. UU. ya cubre Canadá y México. Cambia la lista desplegable de Marketplace a la tienda que quieras y la app reutiliza las mismas credenciales automáticamente. Lo único específico de cada país es tu etiqueta de seguimiento de afiliado: pon tu etiqueta de Amazon Associates de Canadá o México en Etiquetas de afiliado por país (Deeplink Butler, luego Ajustes) para que esas comisiones se registren en la tienda correcta.
- **La Partner Tag de la Creators API es rechazada**: ese campo necesita tu ID de seguimiento de Amazon Associates (como yourtag-20), no tu ID de escaparate.
- **Los campos de credenciales de la Creators API aparecen vacíos tras reiniciar**: es lo esperado. Las claves guardadas se ocultan por seguridad. Solo elige tu marketplace y pulsa Test Connection. No necesitas volver a pegarlas.
- **Una clave nueva de la Creators API falla justo después de crearla**: las claves recién emitidas pueden tardar hasta 24 horas en activarse del lado de Amazon. Espera y vuelve a probar. Si el fallo es el bloqueo de elegibilidad, usa el botón de credenciales de respaldo (mira la sección de credenciales de respaldo más arriba) en vez de esperar.
- **La clave de OpenAI da verde pero la generación falla**: distintos productos de OpenAI usan distintos límites. Una clave válida para completions puede chocar con un problema de billing/quota en un modelo específico. Revisa la pestaña de billing del dashboard de OpenAI.
- **El OAuth de YouTube caduca inesperadamente**: Google rota los tokens OAuth aproximadamente cada año. Vuelve a ejecutar el Setup Wizard de YouTube Butler para refrescar.
- **El enrutamiento de afiliados eligió el proveedor equivocado**: normalmente significa que se marcó el proveedor equivocado. Abre la sección de enrutamiento y verifica los checkboxes de proveedores participantes.
- **No encuentras la tarjeta de Mavely en esta página**: es normal, se movió. El inicio de sesión de Mavely está en Deeplink Butler > Ajustes, consulta el [tutorial de Deeplink Butler](/help/tutorials/link-butler) para la guía completa.
- **Iniciaste sesión en Mavely pero Influencer Butler sigue diciendo que no**: el inicio de sesión solo cuenta dentro del navegador que Influencer Butler reserva para Mavely. Abrir creators.joinmavely.com en tu propio navegador, incluso desde un enlace del aviso de sesión cerrada, te conecta en un sitio que la aplicación no ve. Usa **Iniciar sesión en Mavely** en la tarjeta de Mavely (Deeplink Butler > Ajustes), inicia sesión en la ventana que se abre, ciérrala y haz clic en **Comprobar estado**.
- **Buscas una clave de API de Mavely**: no existe. Mavely es la red que se autentica iniciando sesión en lugar de con una clave pegada, así que su tarjeta no tiene campo de clave a propósito.
- **No encuentras dónde configurar Mavely para Walmart, Target u otra tienda**: no hay configuración por tienda ni por cuenta, por eso no hay nada que encontrar. Mavely deduce el comercio del propio enlace del producto, así que tener la sesión iniciada es toda la configuración. Walmart es la única excepción, porque tiene una opción propia: **Walmart Butler**, luego **Ajustes**, luego **Walmart link provider**, donde **Mavely (mave.ly links)** envía las ofertas de Walmart por Mavely y **Walmart Creator (walmrt.us links)** usa tus propios enlaces de Walmart Creator. Para Target y el resto del catálogo, pega la URL del producto en el cuadro **Product URL** de la tarjeta de Mavely (Deeplink Butler > Ajustes) y pulsa **Create Link**, o usa el botón de enlace de la extensión de Chrome en la página del producto.

## También en la extensión de Chrome

La [extensión gratuita de Chrome de Influencer Butler](/help/tutorials/extension) ahora tiene su propio panel de Integraciones de API, así que puedes conectar los mismos proveedores sin la app de escritorio. Abre la ventana de la extensión y haz clic en el **icono de engranaje** de la esquina superior derecha. Tienes el mismo flujo: pegar una clave, **Probar conexión**, ver la insignia ponerse verde, un botón **Probar todo lo guardado** y un interruptor de prueba al iniciar. Cubre OpenAI, la Amazon Creators API, las etiquetas de Associates por país, los proveedores de deeplink y las redes de afiliados, con los mismos controles de enrutamiento de afiliados y de deeplink principal.

La diferencia importante es dónde viven las claves. En la extensión, tus claves se quedan en tu dispositivo, cifradas en el almacenamiento local del navegador, y solo se envían a la API de cada proveedor (por ejemplo, la clave de OpenAI solo va a OpenAI). Nunca pasan por los servidores de Influencer Butler. Como el acceso a cada proveedor se concede cuando hace falta, la primera vez que pruebas o guardas un proveedor Chrome te pide permiso para que la extensión acceda a su sitio.

Una vez conectados, la extensión los usa mientras navegas por Amazon: un botón **Copiar mi enlace** en cualquier producto crea tu enlace de afiliado/deeplink y, cuando OpenAI está conectado y probado, un botón **Redactar pie de foto** escribe una publicación rápida por ti.

Nota: la prueba de conexión en vivo hace ahora una llamada real de solo lectura para OpenAI y la Amazon Creators API; los proveedores de deeplink y las redes de afiliados validan tu configuración guardada, con comprobaciones en vivo que se añadirán a medida que se confirme el endpoint de cada proveedor.

## Enlace profundo nativo de Amazon

En la parte superior de **DeepLink Routing** está el interruptor **Enlace profundo nativo de Amazon**, activado por defecto. Cuando está activado, cada enlace de producto de Amazon que crean tus herramientas se abre directamente en la app de Amazon en el móvil en lugar de en el navegador, lo que hace la compra más fluida para tus compradores. Es independiente de la lista de proveedores de abajo: el proveedor elige la redirección/acortador, mientras que este interruptor controla la apertura en la app. Desactívalo si prefieres publicar enlaces normales de navegador.

Ten en cuenta una cosa: para que el enlace abra realmente la app, tu cuenta de Amazon Associates también necesita "Deep linking enabled" en SiteStripe. El interruptor añade el formato de enlace correcto; el ajuste de tu cuenta es lo que le dice a Amazon que lo respete.

## Etiquetas de afiliado por país

En **DeepLink Routing** hay una lista desplegable **Etiquetas de afiliado por país**. La mayoría se rellenan solas: cuando ejecutas la comprobación de ID de tienda en **Ajustes**, lee las etiquetas de afiliado de tu cuenta de Amazon y completa automáticamente los países correspondientes. Vuelve a ejecutar la comprobación cuando quieras para actualizarlas. Puedes escribir una etiqueta a mano en cualquier país para anularla, y una etiqueta que escribas se conserva. Tu etiqueta de EE. UU. usa por defecto tu ID de tienda CC; deja un país en blanco para omitirlo.

Estas etiquetas activan las opciones de **Enlaces por país** en Deal Posting. La etiqueta es lo que hace que la comisión se registre en ese país, así que un enlace extranjero solo se publica cuando has añadido su etiqueta.

## Panel de rendimiento de enlaces

**Influencer Butler** también es un proveedor de deeplinks por sí mismo. Elígelo en **DeepLink Routing** y cada enlace que creen tus herramientas se convertirá en un enlace corto de marca en `links.influencerbutler.com` que te pertenece. Está incluido gratis en todos los planes, así que solo inicia sesión y elígelo.

Justo debajo de la lista de proveedores está el panel **Rendimiento de enlaces**. Ábrelo para ver cómo hace clic tu audiencia: clics totales, una tendencia día a día, tus enlaces principales y un desglose por país, dispositivo y referente. Elige un rango de fechas (7, 30 o 90 días) y las cifras se actualizan. Como Amazon no informa las ganancias por enlace saliente, estas son métricas de clics, no de ingresos.

Los enlaces se agrupan por producto, así que volver a publicar el mismo artículo mantiene sus clics juntos en lugar de repartirlos entre muchos enlaces cortos.

## Estado de enlaces

Un enlace de marca es una redirección que te pertenece, así que lo que publicas apunta al enlace corto, no al producto. Eso es lo que hace posible **Estado de enlaces**. Abre el panel **Estado de enlaces** justo debajo de Rendimiento de enlaces y pulsa **Revisar ahora**. Influencer Butler consulta el producto de cada enlace de marca en Amazon y marca los que están agotados o retirados del catálogo. Tu audiencia nunca ve un enlace roto, pero un producto agotado te sigue costando la venta, así que este es el panel que los encuentra antes de que mermen tus ingresos en silencio.

Para cada enlace roto obtienes un producto de reemplazo sugerido (encontrado con la misma coincidencia que usa Retag Butler), o puedes pegar tu propia URL de Amazon. Pulsa **Reapuntar** e Influencer Butler actualiza el destino del enlace en el backend. Como todos los que hacen clic pasan por el enlace corto, cada copia que ya publicaste, en todas las plataformas, empieza a apuntar al producto disponible al instante. No vuelves a publicar nada.

Activa **Revisar automáticamente** para ejecutarlo en segundo plano de forma diaria o semanal, para enterarte en el momento en que un enlace deja de funcionar. Los productos de un mercado para el que no has conectado credenciales de API se marcan como "sin revisar" en lugar de rotos.
